# Gestión de Apuntes

En este menú se dispone de la funcionalidad para crear, contabilizar o descontabilizar masivamente apuntes contables.

**Ruta de acceso:** `Ventas >> Gestión de apuntes`

## Tipos de apuntes

Se pueden gestionar los apuntes de:

- **De facturas:** Gestión y contabilización de apuntes contables derivados de facturas
- **De recibos:** Control y contabilización de apuntes contables de recibos emitidos a clientes
- **De cobros:** Registro de apuntes contables para cobros realizados a clientes

## Funcionalidades principales

### Crear apuntes
Generación de apuntes contables derivados de operaciones de ventas.

### Contabilizar apuntes
Proceso de validación y registro de apuntes en el libro mayor.

### Descontabilizar apuntes
Reversión de apuntes ya contabilizados para correcciones o ajustes.

### Operaciones masivas
Permite realizar estas operaciones de forma masiva sobre múltiples apuntes simultáneamente.

## Integración con módulos

Los apuntes se generan automáticamente en función de:
- Las operaciones realizadas en Facturas
- Los cobros registrados en Recibos
- Las transacciones procesadas en la Gestión de cobros

> Para más información sobre cómo se contabilizan estas operaciones, consultar la documentación de cada módulo específico.
