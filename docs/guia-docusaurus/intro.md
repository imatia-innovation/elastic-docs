# Guía Docusaurus

## Bienvenida a Docusaurus

**Docusaurus** es un generador de sitios web estático moderno, optimizado para crear documentación de proyectos, blogs y sitios de contenido.

### ¿Qué es un generador estático?

Un **generador estático** es una herramienta que convierte tus archivos de contenido (Markdown, etc.) en un sitio web completamente compilado, compuesto por archivos HTML, CSS y JavaScript listos para desplegarse casi en cualquier lugar.

## Conceptos clave

### Documentos
Los **documentos** son grupos de páginas conectadas a través de:
- Un **panel lateral** automático
- Navegación de **página anterior/siguiente**
- Sistema de **versionado**

### Páginas
Las **páginas** son contenidos autónomos que no forman parte de la documentación principal. Pueden crearse en React o Markdown.

### Blog
El **blog** es un sistema integrado que genera:
- Una página para cada entrada
- Una página de índice del blog
- Sistema de etiquetas
- Feed RSS automático
