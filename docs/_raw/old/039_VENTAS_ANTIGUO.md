Manual de Usuario Módulo de Ventas  
 
elastic® BUSINESS  Pág. 39 de 134 Enviado a producción  En este campo se indica el momento en que el pedido 
ha sido enviado a producción.  
Cerrado  Campo que se cubre automáticamente cuando la 
ultima línea del pedido es incluida en un albarán.  
Anulado  Una vez cubierta esta fecha, el pedido pasa a estar 
anulado, moviéndose automáticamente a la carpeta 
de pedidos anulados.  
Plazo  de entrega  Campo disponible para introducir los días previstos para 
la entrega de pedido. Si se cubre la fecha de 
Confirmado, automáticamente se calcula la fecha de 
entrega.  
Previsión entrega  Campo editable de forma manual o, calculado a partir 
del plazo de entrega. Para que se calcule 
automáticamente, se debe cubrir la fecha de 
Confirmado y el Plazo de entrega.  
Ejercicio fiscal  Año fiscal contra el que se ha emitido el pedido.  
Observaciones  Campo texto para exponer cualquier aclaración u 
observación sobre el artículo.  
Encabezado OP  Campo libre para indicar observaciones que queremos 
que salgan en la OP si el pedido va a ir a producción.
