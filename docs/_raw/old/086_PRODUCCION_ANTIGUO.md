Realizar un consumo manual no planificado  
 
1. Despliega el árbol de la izquierda hasta situarte sobre la orden para 
la que quieres realizar un consumo  
2. Entra en la pestaña Consumos.  
3. Haz clic en Añadir registro a la tabla . Se abre la ventana de 
consumos.  
4. Selecciona el detalle para el que se realiza el consumo y marca el 
check No planificado . 
5. Elige familia, artículo y cantidad y valida el consumo.   
 Nota: Un consumo no planificado puede realizarse de 
cualquier artículo dado de alta en la aplicación. Además, no 
restará cantidad reservada. Sí dará de baja en almacén las 
unidades consumidas.  
 Nota: Para realizar fabricaciones de elementos trazables 
consultar el manual de trazabilidad.  
 Nota: Para realizar consumos y altas de paquetes en 
producción consultar el manual de paquetes.
