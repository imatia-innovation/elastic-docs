Manual de Usuario Módulo de Ventas  
 
elastic® BUSINESS  Pág. 34 de 134 Pestaña Datos básicos.  
Pestaña destinada a definir el estado del pedido, la identificación del 
cliente, el vendedor asociado a ese cliente y los datos básicos de valoración 
del pedido.  
 
 Campo  Descripción  ESTADO  Pendiente  Check que se activa automáticamente una vez que el 
pedido se acepta por parte de la empresa.  
Producir  Check que se activa de forma manual  cuando el 
pedido pasa a producción.  
Especial  Check manual. Si se activa el botón de incidencias que 
genera dos albaranes uno positivo y otro negativo para 
que no existan movimientos en el almacén.  DATOS DEL CLIENTE  Dirección  
Datos de la dirección principal por defecto. Dirección a 
la que si no se expresa lo contrario a través del Tipo de 
dirección, se enviará la correspondencia.  Localidad  
Provincia  
C. Postal  
País 
Tipo dirección  Campo para seleccionar direcciones optativas.  DATOS DEL REPRESENTANTE/S  
Representante/s  Nombre del vendedor o representante asociado al 
pedido. Por defecto aparece el que el cliente tiene 
asignado en su ficha o se arrastra del presupuesto pero, 
si queremos podemos reasignar otro de entre los que 
estén asignados a esa empresa.  
Comisión fija  Importe en eurosde comisión fija asignada de forma 
manual al vendedor para cada una de las líneas de ese 
pedido.  
Comisión variable  Valor en % de comisión asignada de forma manual al 
vendedor para cada una de las linea de ese pedido.  DATOS DEL PEDIDO  Condiciones de pago  Combobox para elegir las condiciones de pago 
asociada a cliente. Es configurable según la empresa 
cliente, puede ver todas las dadas de alta en el sistema 
o todas las asociadas a ese cliente según condiciones.  
Forma de pago  Combobox para elegir la forma de pago asociada a 
cliente. En principio solo debería tener una que es la que 
aparecería por defecto.  
Descuento  Combobox en el que se puede seleccionar el 
descuento general que se le quiere aplicar al cliente de 
este pedido. Si se define por defecto un descuento 
asignado al cliente, este aparecerá siempre en el 
combo cuando se cree un pedido.  
Valor fijo  Valor fijo monetario asociado al descuento definido 
anteriormente.
