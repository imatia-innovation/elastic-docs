Formulario Cuentas bancarias  
A través de este formulario, se pueden registrar las diferentes cuentas 
bancarias con las que necesitas  hacer operaciones, así como el tipo de 
relación entre las mismas y las subcuentas definidas en el Plan Contable de 
la empresa.  
El formulario se compone de un área superior donde se introducen una serie 
de datos referentes a la cuenta bancaria, y una tabla de registros que 
muestra los datos relativos a las subcuentas relacionadas con cada cuenta 
bancaria.  
 
 Campo  Descripción   Código cuenta  Código numérico que asigna automáticamente el programa 
a cada cuenta bancaria.  
Empresa  Combo donde seleccionar la empresa a la que se asocia la 
cuenta bancaria.  DATOS BANCARIOS  Banco  Combo para seleccionar el nombre de la entidad bancaria.  
Entidad  Código de 4 cifras que identifica al banco.  
Sucursal  Código de 4 cifras que identifica a la oficina del banco.  
DC Código de 2 cifras para el dígito de control que el programa 
calcula automáticamente según el número de cuenta 
introducido en el último campo.  
Nº cuenta  Código de 10 cifras que identifica la cuenta.  
 Moneda  Combo para seleccionar la moneda asociada a la cuenta 
bancaria.  
 Código cuenta  Código numérico que asigna automáticamente el programa 
a cada cuenta bancaria.  
Plan contable  Número de subcuenta relacionada con la cuenta bancaria.  
Descripción  Texto que define la subcuenta relacionada con la cuenta 
bancaria.  
Ejercicio  Ejercicio contable???  
Tipo Código que identifica el tipo de partida .
