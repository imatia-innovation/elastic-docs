Manual de Usuario Módulo de Ventas  
 
 
elastic® BUSINESS  Pág. 18 de 134 Ejercicio fiscal  Campo modificable  donde por defecto aparece el 
año fiscal en vigor contra el que se va a crear y archivar 
el documento. Servirá para una rápida localización 
dentro del árbol.  
Previsión de entrega  Fecha prevista para entrega de la mercancía. Editable 
de forma manual, tipo dd/mm/aa o a partir del 
calendario adjunto.  
Pestaña Datos básicos  
Pestaña que sirve para definir el estado del presupuesto e identificar al 
cliente.  
 
Además existe la posibilidad de utilizar el campo observaciones  para anotar 
una incidencia o aclaración referente al presupuesto.  
 
 
 
 Campo  Descripción  ESTADO  Presupuesto cerrado  Check que se activa  automáticamente una vez que 
una versión del presupuesto es acepta por parte de la 
empresa y se lanza un pedido. Automáticamente pasa 
a la carpeta de presupuestos cerrados.  
No aceptado  Check que indica si el presupuesto ha sido rechazado 
por el cliente. Una vez guardado el cambio, el 
documento pasa automáticamente a la carpeta de no 
aceptados.  
Anulado  Check que indica si el presupuesto ha sido anulado por 
causas ajenas al cliente. Una vez guardado el cambio, 
el documento pasa automáticamente a la carpeta de 
anulados.  OBSERVACIONES  
Observaciones  Campo libre para definir cualquier tipo de incidencia u 
observación acerca del presupuesto. Sólo se puede 
visualizar en el documento.  DATOS DEL CLIENTE  Un. de negocio  Combobox desplegable donde se selecciona la 
subempresa o delegación contra la que se quiere  crear 
el presupuesto. Los datos de facturación o expedición 
cambian según se  seleccione una unidad de negocio 
distinta.  
Dirección  
Datos de la dirección principal por defecto. Dirección a 
la que si no se indica lo contrario a través del tipo de 
dirección, se enviará la correspondencia.  Localidad
