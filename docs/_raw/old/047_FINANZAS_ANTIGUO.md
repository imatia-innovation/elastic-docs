Formulario Ubicación de Activos  
A través de este formulario se puede especificar la localización física de los 
distintos elementos de inmovilizado.  
La estructura del formulario está compuesta por una tabla de registros, que 
muestra los datos una vez elegida la empresa y el ejercicio, y pulsado el 
botón Mostrar datos . La tabla contiene una serie de columnas:  
 
 Campo  Descripción  
 Código de Ubicación  Código alfanumérico que clasifica la ubicación.  
 Descripción  Texto que define el lugar de ubicación.  
 Situación  Datos sobre la localización física del elemento.
