Ya has creado un presupuesto con una versión. Ahora, puedes crear tantas 
versiones como desees, repitiendo los pasos anteriores. Las versiones siguen 
una numeración correlativa y los puedes consultar en la pestaña Versiones  y 
haciendo doble clic en una de ellas.  
 
Se entiende que una nueva versión es una corrección sobre las líneas o 
características de una versión anterior para un mismo cliente, y no un nuevo 
presupuesto. Esto te permite conservar la evolución del presupuesto según 
las solicitudes del cliente o las distintas ofertas que le realizas.  
 
Si lo que deseas es crear un nuevo presupuesto con las mismas 
características pero para un cliente distinto, es recomendable utilizar las 
opciones Copiar  o Clonar presupuesto , que se explican dentro de este 
capítulo.  
Modificar una versión existente  
Cuando quieras realizar un cambio en una determinada versión de un 
presupuesto, surgen dos posibilidades: sobrescribir o guardar las 
modificaciones sobre la misma versión, o generar una nueva.  
 
1. Selecciona un presupuesto ya existente en el árbol.  
2. Ve a la pestaña Versiones  y abre la versión elegida mediante un 
doble clic.
