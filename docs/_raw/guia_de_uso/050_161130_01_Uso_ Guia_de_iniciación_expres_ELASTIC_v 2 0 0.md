Nuevo ejercicio  
 
Para crear un nuevo ejercicio contable , 
 
Módulo Finanzas >>> Procesos  >>>  Nuevo ejercicio  >>> Nodo Empresas >>>  Insertar (F9) 
>>> Editar y rellenar los campos necesarios  >>> Insertar (F9)  
 
Cerrar ejercicio  
 
Antes de cerrar un ejercicio es necesario tener creado el nuevo ejercicio en el que se va 
a hacer el asiento de apertura correspondiente.  
 
Para cerrar un ejercicio , 
 
Módulo Finanzas >>> Procesos  >>>  Cerrar  ejercicio  >>> Editar y rellenar los campos 
necesarios  >>> Botón Cerrar  
 
Invertir cierre  
 
Una vez cerrado el ejercicio no es posible introducir nuevos asientos en él. La única 
forma de volver atrás es mediante este proceso, que invierte los asientos de 
regularización y cierre, y deja todo tal y como estaba anteriormente . 
 
Para invertir cierre , 
 
Módulo Finanzas >>> Procesos  >>>  Invertir cierre  >>> Editar Empresa y Ejercicio  >>>
