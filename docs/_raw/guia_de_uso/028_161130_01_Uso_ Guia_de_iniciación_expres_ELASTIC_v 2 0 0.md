Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
 
Para crear un nuevo pedido bastará con insertar la cabecera del mismo,  
 
Módulo Compras >>> Pedidos >>> Pestaña Pendientes >>> Añadir registro a la tabla >>> 
Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para insertar líneas con artículos en el pedido (los artículos han de estar previamente 
insertados en la aplicación),  
 
Módulo Compras >>> Pedidos >>> Pestaña Pendientes >>> Doble clic sobre el pedido 
deseado >>> Pestaña Líneas >>> Subpestaña Líneas >>> Botón Artículo de la tabla 
>>> Editar y rellenar los campos necesarios >>> Aceptar  
 
Para generar un albarán a partir de un pedido,  
 
Módulo Compras >>> Pedidos >>> Pestaña Pendientes >>> Doble clic sobre el pedido 
deseado >>> Acciones >>> Generar Albarán  
 
Nota: Las funcionalidades existentes desde pedido de compra son: descompletar, generar 
albarán o albarán y factura y, clonar pedido.  
Albaranes   
Una vez generado el pedido, se puede crear un albarán a partir de este último o, crear 
uno directamente ya que se podría querer insertar varios pedidos en el mismo albarán; o 
partes de pedido, o un albarán directamente sin pedido.  
 
Para crear un nuevo albarán bastará con insertar la cabecera del mismo,  
 
Módulo Compras >>> Albaranes >>> Pestaña No Facturados >>> Añadir registro a la tabla 
>>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para insertar líneas con artículos en el albarán (los artículos han de estar previamente 
insertados en la aplicación),  
 
Módulo Compras >>> Albarán >>> Pestaña No Facturados >>> Doble clic sobre el albarán 
deseado >>> Pestaña Líneas >>> Subpestaña Líneas >>> Botón Artículo de la tabla 
>>> Editar y rellenar los campos necesarios >>> Aceptar
