Guía rápida de iniciación  Configuración y parametrización  
Almacenes y artículos  
El siguiente paso es configurar el módulo de almacén. Aquí se define la estructura lógica 
y/o física de los almacenes / subalmacenes e incluso ubicaciones y el comportamiento que 
deben tener los artículos a la hora de ser generados. Hay que tener en cuenta  que uno de 
los valores diferenciales de elastic® BUSINESS , es que los artículos se pueden crear 
mediante parámetros.  
Una configuración por parámetros de los artículos, permite a posteriori, asociar descuentos 
en base a los valores de los parámetros, o que la propia aplicación autogenere los artículos 
e incluso los despieces de los mismos para producción, tanto a nivel co mponentes como a 
nivel operaciones.  
Esto no implica que obligatoriamente sea necesario configurar los artículos por 
parámetros, sino que elastic® BUSINESS  soporta la creación de artículos convencionales, 
donde es el usuario el que crea el artículo asignándole un código  una descripción.  
Desde aquí también se configuran los almacenes / subalmacenes por defecto asociados a 
cada familia de artículos o temas relacionados con stock´s de seguridad.  
Alta de almacenes, subalmacenes y ubicaciones  
Asociado a cada empresa dada de alta en la aplicación, se puede crear una estructura de 
almacenes, subalmacenes e ubicaciones personalizada. Ello nos permite tener incluso una 
misma base de datos de artículos compartida para cada empresa y controlar tanto las 
existencias totales por empresa o de manera conjunta y, si fuese necesario a nivel de cada 
subalmacén y ubicación.  
Como ya se comentó en alguna ocasión, aunque la aplicación es multiempresa no es 
conveniente crear para una misma entidad de servidor y por tanto bajo una misma 
aplicación, empresas totalmente distintas desde el pto. de vista productivo o de 
comercializaci ón de producto ya que la base de productos se comparte para todas ellas. 
De alguna manera deben estar relacionadas.  
Para dar de alta almacene s, subalmacenes y/o una ubicación/ es, proceder de la siguiente 
manera:  
Para crear un almacén,  
 
Menú Almacén >>> Instalaciones >>> Seleccionar Empresa en el árbol >>> Añadir Registro 
>>> Editar y rellenar los campos necesarios >>> Insertar (F9)
