Oportunidades   
En este apartado explicaremos al detalle cómo dar de alta una oportunidad con todos sus 
datos así como toda su gestión.  Para ello se deben seguir los pasos enumerados a 
continuación , 
 
Módulo CRM >>> Oportunidades  >>> Pestaña Oportunidades  >>> Añadir registro a la 
tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
En el Registro de proyectos se accede a un resumen de todas las oportunidades abiertas , 
 
Módulo CRM >>> Oportunidades  >>> Pestaña Registro de proyectos   
Tareas   
En la cabecera del formulario de tareas aparecen los datos para el filtrado de las mismas 
en las pestañas, así como los botones para crear los diferentes tipos de tareas . 
Para crear un a nueva tarea , 
 
Módulo CRM >>> Tareas  >>> Tareas  >>> Añadir registro a la tabla >>> Editar y rellenar 
los campos necesarios >>> Insertar (F9)  
 
Nota: También es posible crear tareas dentro de las Cuentas, Contactos, Eventos, 
Campañas y Oportunidades. En concreto en la pestaña Tareas de cada uno de estos 
formularios.   
 
Para visualizar la lista de tareas existente , 
 
Módulo CRM >>> Tareas  >>> Tareas  >>> Ir a la pestaña deseada  >>> Botón Mostrar  datos
