Orden de preparación   
Las órdenes de preparación son un paso intermedio entre el pedido y el albarán que 
permite determinar los envíos que han de ser preparados para expedición . 
Para crear una orden de preparación,  
 
Módulo Ventas >>> Pedidos  >>> Pestaña No Expedidos >>> Doble clic sobre el pedido a 
preparar  >>> Acciones >>> Generar orden de preparación  >>> Seleccionar las 
líneas y cantidades a preparar  >>> Aceptar  
 
Para consultar los datos de todas las órdenes de preparación,  
 
Módulo Ventas >>> Ordenes de preparación  
Albaranes   
Una vez generado el pedido, se puede crear un albarán a partir de este último o, crear 
uno directamente ya que se podría querer insertar varios pedidos en el mismo albarán; o 
partes de pedido, o un albarán directamente sin pedido.  
 
Para crear un nuevo albarán bastará con insertar la cabecera del mismo,  
 
Módulo Ventas >>> Albaranes >>> Pestaña No Expedidos >>> Añadir registro a la tabla 
>>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para insertar líneas con artículos en el albarán (los artículos han de estar previamente 
insertados en la aplicación),  
 
Módulo Ventas >>> Albarán >>> Pestaña No Expedidos >>> Doble clic sobre el albarán 
deseado >>> Pestaña Líneas >>> Subpestaña Líneas >>> Botón Artículo de la tabla 
>>> Editar y rellenar los campos necesarios >>> Aceptar
