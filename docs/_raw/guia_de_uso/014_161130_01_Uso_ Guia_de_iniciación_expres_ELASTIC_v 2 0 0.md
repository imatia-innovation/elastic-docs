Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Por representante comercial se entiende a personas jurídicas, empresas que actúan como 
“freelance” o persona l en plantilla que se dedican a labores de venta comercial, 
principalmente . 
 
Para crear un comercial , 
 
Módulo Ventas >>> Comerciales  >>> Comerciales  >>> Nodo Todos en el árbol >>> Insertar 
(F9) >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para asignar un cliente y una comisión a un comercial,  
 
Módulo Ventas >>> Comerciales >>> Comerciales >>> Seleccionar el comercial en el árbol 
>>> Pestaña Comisiones >>> Añadir registro a la tabla >>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)  
 
Nota: Para realizar esta última tarea es necesario primero tener creadas las comisiones.  
Comisiones   
Es posible  crear comisiones fijas, comisiones variables inversamente proporcionales al 
descuento que aplica el comercial en la venta, comisiones asignadas a familias de 
artículos, etc.  Lo único que no se permite es tener varias comisiones tanto fija, variable 
o de familia para un mismo cliente / representante, ya que  las comisiones no se 
concatenan un as con otr as 
 
Para configurar las comisiones primero ha de crearse el tipo o modelo de comisión,   
 
Módulo Ventas >>> Comerciales  >>> Configuración de comisiones  >>> Limpiar campos 
(ALT Supr)  >>> Insertar (F9)  >>> Editar y rellenar los campos necesarios >>> 
Insertar (F9)  
 
Una vez creado el tipo de comisión es necesario crear las comisiones valoradas dentro 
del mismo,   
 
Módulo Ventas >>> Comerciales  >>> Configuración de comisiones  >>> Seleccionar en 
árbol el tipo de comisión >>> Subnodo Comisión >>> Insertar (F9)  >>> Editar y 
rellenar los campos necesarios >>> Insertar (F9)
