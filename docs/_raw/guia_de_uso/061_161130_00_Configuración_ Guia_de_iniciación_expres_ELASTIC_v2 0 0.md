VER VIDEO. Como crear tarifas.  
Crear descuentos generales o de línea asociados a los artículos dependiendo de 
valores de parámetros  
Sobre el precio de venta definidos para cada uno de los artículos de una tarifa, se pueden 
realizar diferentes políticas de descuento según las necesidades de la empresa.  Dichos 
descuentos pueden ser generales y por tanto asociados a todos los artículos a ñadidos en 
un presupuesto, pedidos, etc… o bien pueden ser descuentos de línea asociado a una sola 
o a varias líneas de un presupuesto pero no a su totalidad. Además estos últimos, 
aprovechando el potencial de los parámetros, se puede configurar que un art ículo tenga 
determinado valor de descuento de línea si cumple determinada condición relacionado con 
uno o varios valores de uno o varios parámetros. De esta manera será el propio sistema 
que se encargue de proponer el descuento asociado a una línea con opc ión a modificarlo 
manualmente. La configuración dependiendo del parámetro es para todo el sistema y no a 
nivel cliente.  
 
Para crear un descuento,  
 
Módulo Ventas >>> Descuentos >>> Insertar (F9)>>> Editar y rellenar los campos necesarios 
(general o de línea) >>> Insertar (F9)  
 
Para asignar los clientes que tendrá dicho descuento,  
 
Módulo Ventas >>> Descuentos >>> Seleccionar Descuento en el árbol >>> Tabla Clientes 
>>> Añadir Registro a la tabla >>> Asociar Clientes >>> Aceptar
