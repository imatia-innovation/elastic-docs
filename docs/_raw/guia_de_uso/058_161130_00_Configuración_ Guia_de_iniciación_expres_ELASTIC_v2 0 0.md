Además esto permite tener varios modelos con comportamientos diferentes para familias 
diferentes.  
 
Para configurar un modelo de coste proceder de la siguiente manera:  
 
Menú Almacén >>> Modelo de costes >>> Insertar (F9) >>>Insertar datos de cabecera >>> 
Insertar (F9).  
 
Para modificar o añadir los parámetros que van a definir el modelo de costes:  
 
Menú Almacén >>>  Modelo de costes >>> Localizar en el árbol el modelo de costes >>> 
Añadir o modificar los registros correspondientes a los parámetros que se quieren 
tener en cuenta en el modelo de  costes.  
 
Ya creados los modelos se deben añadir a las familias, para ello:   
 
Menú Almacén >>> Familias de artículos >>> Seleccionar Familia en el árbol >>> Pestaña 
Costes >>> Asociar modelo de costes para cada versión y determinar cuál es la que 
va a permanecer activa.  
 
A nivel artículo se puede personalizar el modelo de costes. Si un artículo por lo que sea no 
tiene que tener el mismo comportamiento que el resto de la familia se puede editar 
el modelo asociado:  
 
Menú Almacén >>> Familias de artículos >>> Seleccionar Familia en el árbol >>> Pestaña 
Artículos >>> Seleccionar el articulo a modificar >>> Costes >>> doble clic sobre la 
línea del modelo >>> Editar o modificar lo que corresponda.  
 
 Nota: Cuando se configura el modelo de costes se puede llegar a definir para un parámetro 
un valor fijo o un valor variable en base a un porcentaje vinculado a otros parámetros en 
este caso solo a materia prima, mano de obra y máquina. Ejem: coste transporte = 3 % 
Valor de la materia prima.
