Tarifas   
Las tarifas se pueden asociar a los distintos clientes y cada cliente puede tener una o 
varias tarifas asociadas. Esto permite tener varios precios para cada artículo, establecer 
precios por temporada y tener una referencia de precios anteriores ante modificaciones 
de las tarifas.  
 
Para dar de alta una tarifa primero será necesario crear su cabecera,  
 
Módulo Ventas >>> Tarifas  >>> Nodo Vigentes en el árbol  >>> Insertar (F9 ) >>> Editar y 
rellenar los campos necesarios >>> Insertar (F9)  
 
Una vez creada la cabecera han de asignarse los artículos y precios,  
 
Módulo Ventas >>> Tarifas  >>> Seleccionar la tarifa  en el árbol >>> Pestaña Artículos >>> 
Botón Añadir artículos en la tabla  >>> Seleccionar la familiar de artículos a añadir 
a la tarifa >>> Asociar los artículos e insertar el precio  >>> Aceptar  
 
Para indicar que clientes tendrán asociadas una tarifa,  
 
Módulo Ventas >>> Tarifas  >>> Seleccionar la tarifa  en el árbol >>> Pestaña Clientes >>> 
Botón Añadir clientes en la tabla  >>> Asociar Clientes  >>> Aceptar  
Recibos   
El formulario de recibos consta de un grupo de cinco pestañas que permite clasificar los 
recibos en función de su estado, pudiendo acceder a un recibo cualquiera mediante 
doble clic.  
 
Para fraccionar un recibo,  
 
Módulo Ventas >>> Recibos >>> Doble clic sobre el Recibo deseado >>> Acciones >>> 
Fraccionar >>> Añadir Fracción y editar su importe >>> Aceptar
