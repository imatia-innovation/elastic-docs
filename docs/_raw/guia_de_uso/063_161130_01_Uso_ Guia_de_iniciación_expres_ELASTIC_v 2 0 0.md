Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Módulo Producción  >>> Familias de producción  >>> Seleccionar la familia a la que 
asignar el registro de fabricación  >>> Acciones >>> Registros de fabricación  (o 
ensayos)  >>> Añadir registro a la tabla >>> Editar y rellenar los campos necesarios 
>>> Insertar (F9)  
 
Para realizar los registros de fabricación asociados a las órdenes de producción ,  
 
Módulo Producción  >>> Órdenes de producción  >>> Doble clic sobre la orden de 
producción correspondiente  >>> Pestaña Detalles Orden >>> Pulsar botón derecho 
sobre una línea de Detalles Orden >>> Crear nuevo registro de fabricación (o Crear 
nuevo ensayo de calidad) >>> Seleccionar el tipo de registro (o ensayo) a crear >>> 
Aceptar >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Nota: La orden de producción ha de estar lanzada para poder asignarle registros de 
fabricación o ensayos de calidad .  
 
Para realizar un ensayo de calidad en compras,   
 
Módulo Compras  >>> Albaranes  >>> Doble clic sobre el albarán correspondiente  >>> 
Pestaña Líneas >>> Pulsar botón derecho sobre una línea del albarán >>> Crear 
nuevo ensayo de calidad >>> Seleccionar ensayo a crear >>> Aceptar >>> Editar y 
rellenar los campos necesarios >>> Insertar (F9)
