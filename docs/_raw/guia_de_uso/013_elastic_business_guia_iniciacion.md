A continuación se enumerarán de manera clara y concisa a modo de resumen, los pasos a

Clientes y gestión de documentos    
El cliente es la entidad en torno la que gira todo el proceso de ventas . En esta entrada es 
posible crearlos y gestionar sus datos generales . 
 
Para crear un nuevo cliente , 
 
Módulo Ventas >>> Clientes  >>> Pestaña Activos  >>> Añadir registro a la tabla >>> Editar 
y rellenar los campos necesarios >>> Insertar (F9)  
 
La gestión de lo s documentos permite consultar l os documentos de ventas (presupuestos, 
pedidos, albaranes, facturas , recibos , etc… ) de un cliente . 
 
Para visualizar los documentos de un cliente,  
 
Módulo Ventas >>> Gestión de documentos  >>> Seleccionar el cliente en el campo del 
mismo nombre  >>> Acceder a la pestaña del documento a consultar  
 
Nota: También se puede acceder a gestión de documentos desde el propio cliente, ya 
con toda su información filtrada.
