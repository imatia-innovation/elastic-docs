Configuración cuentas cliente/proveedor  
Cada vez que se crea un cliente o un proveedor, se tiene la posibilidad de que se genere 
automáticamente la cuenta contable asociada al mismo. En caso de querer que se 
comporte así y no generarla manualmente en la propia ficha, se debe preconfigurar la 
generación de las cuentas contables.  
Para acceder a la configuración de cuentas contables de cliente / proveedor:  
 
Menú Aplicación >>> Configuración >>> Configuración cuentas cliente/proveedor >>> 
Añadir registro >>> Configurar el comportamiento de generación  >>> Insertar (F9).  
 
 Nota: Una configuración típica puede ser la que se muestra a continuación.
