Libro diario  
 
El Diario es el registro cronológico de las operaciones contables que muestra los nombres 
de las cuentas, los cargos y abonos que en ellas se realizan, así como cualquier 
información complementaria que se considere útil para apoyar la correcta aplicación 
contable de las operaciones realizadas .  
 
Para obtener el diario , 
 
Módulo Finanzas >>> Informes  >>>  Libro diario  >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Mostrar datos  
 
Libro mayor  
 
En el libro mayor se reflejan cada una de las cuentas y las operaciones registradas en el 
libro diario, de manera que se pueda saber el saldo que va quedando en cada cuenta por 
dichas operaciones .  
 
Para obtener el mayor , 
 
Módulo Finanzas >>> Informes  >>>  Mayor  >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Mostrar datos  
 
IVA y RE  
 
Para obtener el listado de IVA y RE , 
 
Módulo Finanzas >>> Informes  >>>  IVA y RE  >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Mostrar datos
