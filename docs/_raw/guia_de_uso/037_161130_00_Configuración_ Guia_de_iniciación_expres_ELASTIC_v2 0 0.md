Guía rápida de iniciación  Configuración y parametrización  
Una vez creado el nuevo perfil, se han de definir los permisos:  
 
Menú Gestión de módulos >>> Perfiles >>> Botón Permisos >>> deshabilitar lo que no 
corresponda >>> Pulsa Aceptar.  
 
▪ En la pestaña Formulario indicar que botones y campos que no estarán 
visibles o bloqueados para dicho perfil.  
▪ En la pestaña Entidad indicar las acciones estándar (Buscar, Actualizar, 
Borrar e Insertar) disponibles para cada perfil.  
 
 Nota: Si se quiere bloquear u ocultar un campo, tabla o botón para un perfil en un 
determinado formulario, se ha de llevar a cabo este proceso en cada formulario.  
 
▪ En la pestaña Menú indicar que menús, entradas y formularios no estarán 
visibles o bloqueadas para cada perfil.  
 
 Nota: Lo normal es configurar los menús,  ya que permite restringir el acceso a 
determinadas zonas de la aplicación.  
 Nota: A pesar de estar editables, no es aconsejable modificar los xml, tanto de cliente 
como de servidor, ya que puede tener graves consecuencias para el funcionamiento de la 
aplicación.  
 Nota: Para facilitar la labor de mantenimiento de perfiles a posteriori, se debe pensar en 
crear perfiles genéricos o perfiles que aglutinen a varios usuarios. LA creación e un perfil 
por usuario debe ser un último recurso a no ser que sea estrictamente necesari o.  
 
VER VIDEO. Crear un nuevo perfil.  
Crear ejercicio contable  
Importante, una vez creada la empresa, usuarios y perfiles, lo próximo es crear el ejercicio 
contable para la empresa. Esto debe hacerse siempre y cuando se vaya a utilizar el módulo 
de Finanzas de elastic® BUSINESS .  
Si se van a exportar los movimientos contables generados en gestión a una aplicación 
externa, no es necesario. Para ello hay una tabla especifica en las tablas de configuración 
“Aplicación >>> Configuración >>> Tablas maestras >>> FINANZAS. Partidas contables. 
Relación de subcuentas a usar SIN MODULO DE FINANZAS.” , para definir que cuentas 
contables se van a utilizar en la aplicación
