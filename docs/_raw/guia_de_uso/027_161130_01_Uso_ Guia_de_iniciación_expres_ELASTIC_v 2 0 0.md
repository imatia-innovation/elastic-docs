Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
 
Para crear un nuevo presupuesto bastará con insertar la cabecera del mismo,  
 
Módulo Compras >>> Presupuestos >>> Pestaña Abiertos >>> Añadir registro a la tabla 
>>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para insertar líneas con artículos en el presupuesto (los artículos han de estar 
previamente insertados en la aplicación),  
Módulo Compras >>> Presupuestos >>> Pestaña Abiertos >>> Doble clic sobre el 
presupuesto deseado >>> Pestaña Líneas >>> Subpestaña Líneas >>> Botón Artículo 
de la tabla >>> Editar y rellenar los campos necesarios >>> Aceptar  
 
Nota: También es posible añadir líneas en blanco, con conceptos o artículos no definidos 
en la aplicación utilizando el botón Añadir líneas en blanco  de la tabla de la pestaña 
Líneas .  
Nota: También es posible llevar a cabo una inserción rápida de artículos a partir de su 
código utilizando el botón Inserción rápida  en la tabla de la pestaña Líneas .  
Nota: También es posible llevar a cabo una inserción de artículos a partir de l 
configurador si se utilizan artículos parametrizados.  
 
Para crear una nueva versión dentro de un mismo presupuesto,  
 
Módulo Compras >>> Presupuestos >>> Pestaña Abiertos >>> Doble clic sobre el 
presupuesto deseado >>> Acciones >>> Nueva versión  
 
Para generar un pedido a partir de un presupuesto,  
 
Módulo Compras >>> Presupuestos >>> Pestaña Abiertos >>> Doble clic sobre el 
presupuesto deseado >>> Acciones >>> Generar Pedido  
 
Nota: También se puede clonar presupuestos para el mismo u otro proveedor.  
Pedido   
Siguiendo la coherencia de diseño en los documentos del flujo de compras, la ventana 
del pedido posee dos secciones perfectamente diferenciadas, en la parte superior la 
cabecera y en la parte inferior un conjunto de pestañas donde se muestran los datos e  
información referentes al pedido.
