Alta de parámetros y configuraciones de ensayos de calidad  
Para llevar a cabo los ensayos de calidad la primera tarea será definir los parámetros o 
variables que aparecen en los informes de dichos ensayos  
 
Dar de alta parámetros,  
Módulo Calidad >>> Configuración de ensayos >>> Gestión de parámetros de ensayo >>> 
Añadir Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar 
(F9) 
Para crear una configuración de ensayos,  
Módulo Calidad >>> Configuración de ensayos >>> Configuraciones de ensayo >>> Añadir 
Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
Para asignar los parámetros anteriormente creados a una configuración de ensayos,  
Módulo Calidad >>> Configuración de ensayos >>> Configuraciones de ensayo >>> Doble 
clic sobre un Tipo de Configuración >>> Añadir Registro a la tabla >>> Editar y 
rellenar los campos necesarios >>> Insertar (F9)
