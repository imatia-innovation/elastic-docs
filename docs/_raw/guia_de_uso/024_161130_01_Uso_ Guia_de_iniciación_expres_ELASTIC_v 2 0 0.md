Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Módulo Ventas >>> Cobros >>>  Pestaña Enviadas >>> Doble clic sobre el Cobro 
deseado>>> Pestaña Pendientes >>> Seleccionar Recibos >>> Botón Cobrar Recibos 
en la tabla  
 
Para devolver recibos de la remesa de cobro,  
 
Módulo Ventas >>> Cobros >>>  Pestaña Enviadas >>> Doble clic sobre el Cobro 
deseado>>> Pestaña Pendientes >>> Seleccionar Recibos >>> Botón Devolver 
Recibos en la tabla  
 
Nota: Una vez devuelto el recibo es necesario generar los recibos hijos para poder volver 
a enviar el recibo al cobro.  
 
Para validar la remesa de cobro,  
 
Módulo Ventas >>> Cobros >>>  Pestaña Enviadas >>> Doble clic sobre el Cobro 
deseado>>> Rellenar Fecha de Validación >>> Actualizar (F11)  
 
Para generar los cuadernos N19 o C58,  
 
Módulo Ventas >>> Cobros >>> Doble clic sobre el Cobro deseado>>> Acciones  
Gestión de apuntes (facturas, recibos y cobros)   
Mediante la gestión de apuntes es posible crear y borrar apuntes masivamente, pudiendo 
contabilizarlos o descontabilizarlos también de forma masiva.  
 
Para generar apuntes de facturas, recibos o remesas de cobro,  
 
Módulo Ventas >>> Gestión de Apuntes >>>  De Facturas, De recibos o De cobros >>> 
Pestaña No contabilizadas >>> Seleccionar Filas en la tabla que no tengan apuntes 
generados >>> Botón Crear  
 
Para borrar apuntes de facturas, recibos o remesas de cobro,  
 
Módulo Ventas >>> Gestión de Apuntes >>>  De Facturas, De recibos o De cobros >>> 
Pestaña No contabilizadas >>> Seleccionar Filas en la tabla con apuntes 
generados>>> Botón Borrar
