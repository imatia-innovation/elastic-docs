Guía rápida de iniciación  Configuración y parametrización  
Una vez creado el parámetro, se necesita dar valores posibles del mismo. Para ello 
proceder de la siguiente manera:  
 
Módulo Almacén >>> Parámetros >>> Localizar el parámetro >>> Añadir detalle sobre la 
línea >>> Dar los valores del parámetro. Tantos como sean necesarios.  
 
 Nota: El sistema crea automáticamente el parámetro familia, este se distingue porque 
aparece en rojo en el momento de crear las familias.  
 Nota: El tipo de parámetros puede ser Explícito o Implícito. Será Implícito cuando su valor 
pueda ser uno de una lista determinada de valores posibles. Dichos valores serán definidos 
en la tabla Valores. Por el contrario si el valor es explicito no es necesario cargar valores 
previamente, ya que este se informa en el momento de crear el artículo. Esto nos permite 
tener parámetros tipo dimensiones sin precargar el rango infinito de valores posibles. Lo 
que si se puede configurar es el rango de uso que puede  llegar a tener un parámetro  
 Nota: Independientemente de cómo se configuren los parámetros, cuando estos se utilizan 
para configurar las familias y se personaliza su configuración, esta es la que prevalece 
sobre la genérica. En la configuración se puede decidir si el parámetro se va utiliza r para 
generar código, descripción,  etc… 
 Nota: Los parámetros son reutilizables, quiere decirse que si se crea el parámetro color, 
aunque hay familias que solo utilicen determinados colores en su configuración, estos 
pueden personalizarse sin necesidad de crear un Color1familia Color2familiaB.

Alta de familias

torno a familias y por tanto, la creación de la propia estructura de familias es quizás el 
segundo pto. más importante. Esto se convierte en tanto más importante, dep endiendo de 
si se decide configurar los artículos por parámetros o no.
