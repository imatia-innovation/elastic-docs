Gestión de almacén   
Desde Gestión de almacén se controla el stock que hay en cada uno de los almacenes, 
subalmacenes y ubicaciones. Navegando por el árbol, se accede a los formularios 
correspondientes a cada una de las instalaciones.  
 
Para realizar una entrada de material,  
 
Módulo Almacén >>> Gestión de Almacén >>>  Seleccionar en el árbol el subalmacén o 
almacén principal >>> Pestaña Movimientos >>> Subpestaña  Entradas >>> Añadir 
Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para realizar una salida de material,  
 
Módulo Almacén >>> Gestión de Almacén >>>  Seleccionar en el árbol el subalmacén o 
almacén principal >>> Pestaña Movimientos >>> Subpestaña Salidas >>> Añadir 
Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para realizar un traspaso de material,  
 
Módulo Almacén >>> Gestión de Almacén >>>  Seleccionar en el árbol el subalmacén o 
almacén principal >>> Pestaña Movimientos >>> Subpestaña Traspasos >>> Botón 
Traspaso Artículos en la tabla >>> Editar y rellenar los campos necesarios >>> 
Insertar (F9)  
 
Para realizar una regularización,  
 
Módulo Almacén >>> Gestión de Almacén >>>  Seleccionar en el árbol el subalmacén o 
almacén principal >>> Pestaña Movimientos >>> Subpestaña Regularizaciones >>> 
Añadir Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar 
(F9)
