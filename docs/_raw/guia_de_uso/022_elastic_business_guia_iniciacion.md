Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Los recibos pueden darse por cobrados directamente sin necesidad de incluirlos en un 
cobro para enviar al banco,  
 
Módulo Ventas >>> Recibos >>> Doble clic sobre el Recibo deseado >>> Rellenar Fecha de 
cobro>>> Actualizar (F11)  
 
Para generar los apuntes de un recibo,  
 
Módulo Ventas >>> Recibos >>> Doble clic sobre el Recibo deseado >>> Pestaña Apuntes 
>>> Botón Crear en Generación de apuntes de recibo  
 
Para contabilizar los apuntes generados en el punto anterior,  
 
Módulo Ventas >>> Recibos >>> Doble clic sobre el Recibo deseado >>> Pestaña Apuntes 
>>> Botón Contabilizar en Generación de apuntes de recibo  
Agrupación de recibos   
Para ahorrar costes de gestión bancaria, cabe la posibilidad de juntar una serie de 
recibos de un mismo cliente bajo una única agrupación, de manera que se pueda trabajar 
con todos ellos como si fueran un único recibo, facilitando su envío a cobro.  
Para crear una agrupación de recibos,  
 
Módulo Ventas >>> Agrupación de Recibos >>> Pestaña Pendientes >>> Botón Crear 
agrupación de recibos >>> Editar y rellenar los campos necesarios >>> Aceptar  
 
Para quitar un recibo de una agrupación,  
 
Módulo Ventas >>> Agrupación de Recibos >>> Doble clic sobre el recibo deseado>>> 
Pestaña Recibos Agrupados >>> Seleccionar el recibo a quitar de la agrupación >>> 
Botón Quitar Recibos de la tabla  
Anticipos   
Con la función de anticipos es posible gestionar aportaciones por parte de clientes a 
fondo de posibles compras futuras por su parte o gestionar transferencias adelantadas a 
cuenta de facturas que todavía no han sido emitidas. Es decir, con esta herramienta se 
puede gestionar el cobro de recibos (anticipos) sin necesidad de emitir facturas.
