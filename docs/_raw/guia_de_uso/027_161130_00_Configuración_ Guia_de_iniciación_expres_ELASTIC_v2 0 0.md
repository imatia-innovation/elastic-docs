Instalación aplicación  
 
Para instalar la aplicación se debe disponer de una base de datos vacía de elastic®  
BUSINESS  y de un fichero con la aplicación.  
 
1. En primer lugar se va a crear la base de datos de la aplicación. La base de datos 
debe tener un extensión .bak, puede ser que está se distribuya en formato 
comprimido, por lo que habría que descomprimirla previamente. Una vez lista la 
copia de la base de datos, se debe abrir la aplicación SQL Server Management Studio  
que se instaló anteriormente. Se accede al servidor de bases de datos como se indicó 
anteriormente. Se pulsa sobre el nodo bases de datos (Databases), se despliega  el 
menú con el botón derecho del ratón y se selecciona Nueva base de datos  (New 
database). Aparece la siguiente pantalla en la que se debe establecer un nombre 
para la base de datos y se pulsa el botón “Aceptar” (OK).  
 
 
 
2. Una vez creada, en el nodo bases de datos, aparece la nueva base de datos. Se pulsa 
el botón derecho del ratón sobre ella y se selecciona Tareas  >>> Restore >>> 
Database.  Aparece la siguiente pantalla en la que se elige la opción Desde disco
