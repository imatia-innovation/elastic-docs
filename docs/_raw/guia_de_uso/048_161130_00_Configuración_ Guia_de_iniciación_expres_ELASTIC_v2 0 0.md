Personalizar Plan General Contable  
A partir del plan general contable estándar, el usuario puede personalizar el mismo. La 
personalización va desde crear una nueva cuenta contable, hasta modificar la descripción 
de una cuenta ya existente.  
Para personalizar el Plan General contable, proceder de la siguiente manera, según lo que 
se quiera hacer:  
Si se quiere crear una cuenta nueva:  
 
Menú Finanzas >>> Subcuentas >>> Mostrar datos >>> Añadir registro >>> Configurar la 
nueva subcuenta >>> Insertar (F9).  
 
Si se quiere modificar una cuenta ya creada:  
 
Menú Finanzas >>> Subcuentas >>> Mostrar datos >>> Doble clic sobre la línea de registro 
>>> Modificar >>> Insertar (F9).  
 
 Nota: Cuando se personaliza el PGC una de las tareas a realizar es asoc iar el Tipo / Subtipo 
a todas a quellas subcuentas que van a intervenir en l a parte de gestión. A través de esta 
codificación el sistema sabe interpretar l a tipología de las mismas.

Crear plantillas de apuntes  
Para facilitar la introducción de los asientos, además de insertarlos manualmente, elastic® 
BUSINESS cuenta con la posibilidad de realizarlo mediante plantillas.  A través de las 
plantillas se puede insertar de una manera fácil y cómoda asientos repetitivo s o no en el 
PGC de una manera más ágil.
