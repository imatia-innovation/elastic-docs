Configuración tipo de cliente  
A cada tipo de cliente, se le puede asociar una configuración estándar, es decir, una serie 
de valores precargados (moneda, idioma, IVA,…) de modo que, cada vez que se cree uno, 
se cargan automáticamente dichos valores. Otra funcionalidad interesante es la  de poder 
asignar a un tipo o grupo de clientes una misma cuenta contable o grupo de subcuentas 
contables.

Primero crear una configuración,  
Menú Aplicación >>> Configuración >>> Configuración de clientes >>> Configuración >>> 
Insertar (F9) >>> Editar y rellenar los campos necesarios >>> Insertar (F9)
