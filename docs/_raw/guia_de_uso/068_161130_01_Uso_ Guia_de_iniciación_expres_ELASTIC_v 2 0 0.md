Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
 
Para crear plantillas de email tanto para a las distintas impresiones de documentos de 
Elastic (presupuestos, pedidos, facturas,...) como para mailing en eventos y campañas,  
 
Módulo CRM >>> Configuración  >>> Configurar plantillas de email  >>> Limpiar campos 
(ALT Supr) >>> Insertar (F9) >>> Editar y rellenar los campos necesarios >>> 
Insertar (F9)  
 
Para asociar las plantillas de email creadas a las distintas impresiones de documentos de 
Elastic (presupuestos, pedidos, facturas,...) , 
 
Módulo CRM >>> Configuración  >>> Configurar plantillas para impresiones  >>> Añadir 
registro a la tabla  >>> Editar y rellenar los campos necesarios >>> Aceptar  
 
Para definir los diferentes productos de marketing,  
 
Módulo CRM >>> Configuración  >>> Productos  >>> Insertar (F9)>>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)
