Guía rápida de iniciación  Configuración y parametrización  
La configuración del calendario es opcional, ya que la finalidad de este calendario es 
determinar las horas disponibles del personal o de las secciones de la empresa para 
determinar la capacidad del sistema desde el punto de vista productivo.  
Si la empresa decide utilizarlo como un gestor de vacaciones, obteniendo información tal 
como cuantos días de vacaciones le queda, etc… verá limitada su funcionalidad.  
Insistiendo de nuevo, la funcionalidad del calendario de elastic® BUSINESS, es la de crear 
calendarios maestros de vacaciones o personalizados, contemplando paradas, incidencias, 
turnos, etc… y asociarlo a grupo de trabajadores o a cada uno el suyo. Lo mismo con las 
secciones.  
Esto nos permite de una manera visual determinar cuál es la capacidad que tiene la 
estructura productiva definida para la empresa.  
Para configurar el calendario proceder de la siguiente manera:  
 
Menú Aplicación >>> Configuración >>> Configuración de calendario >>> Insertar (F9) >>> 
Configurar los turnos, días hábiles, vacaciones, etc… >>> Insertar (F9).  
 
Una vez creado el/los calendario/s el siguiente paso es asociarlo o bien a usuarios o a 
secciones.  
 
VER VIDEO. Configurar crear un calendario y como asociarlo a usuarios y secciones. 
Comprobar capacidad productiva resultante.  
Configuración de contadores  
En la aplicación existen dos tipos de contadores:  
▪ Los generales . La aplicación dispone por defecto de una serie de 
contadores generales para los distintos documentos o entidades de la 
aplicación. Dichos contadores generales son solo numéricos, precedidos 
del año en curso. Estos se resetean automáticamente año a año. Si no se 
configuran los particulares por defecto elastic© BUSINESS utiliza estos 
últimos.  
Si por cualquier motivo se necesitase acceder a ellos para modificar el contador, estos se 
localizan en:  
 
Menú Gestión Módulos >>> Contadores >>> Generales >>> Editar o Generar según 
corresponda.
