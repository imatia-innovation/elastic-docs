Facturas emitidas  
 
Este formulario nos muestra el total de facturas emitidas por la empresa, en el ejercicio 
seleccionado. Las facturas emitidas son aquellas que la empresa envía a los clientes, por 
la venta de un determinado bien o servicio.  
 
Para obtener el informe de facturas emitidas , 
 
Módulo Finanzas >>> Informes  >>>  Facturas emitidas  >>>   Editar y rellenar los campos 
en la cabecera >>>  Botón Mostrar datos  
 
Modelo 303  
 
El Modelo 303 es el de la declaración mensual o trimestral del I.V.A., en régimen 
general.  
 
Para imprimir el modelo 303 , 
 
Módulo Finanzas >>> Informes  >>>  Modelo 303  >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Obtener datos >>> Botón Generar informe  
 
Modelo 340  
 
El Modelo 340 permite generar un fichero electrónico para la importación en la oficina 
virtual de la agencia tributaria con  la declaración informativa de facturas expedidas y 
recibidas .  
 
Para generar  el modelo 340 , 
 
Módulo Finanzas >>> Informes  >>>  Modelo 340  >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Obtener datos >>> Botón Generar informe >>> Guardar el 
archivo en la ruta deseada >>> Aceptar
