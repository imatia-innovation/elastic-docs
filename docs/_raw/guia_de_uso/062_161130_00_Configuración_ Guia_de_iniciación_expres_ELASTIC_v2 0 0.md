Guía rápida de iniciación  Configuración y parametrización  
Módulo Ventas >>> Descuentos >>> Seleccionar Descuento de línea en el árbol >>> Pulsar 
Condición (E) >>> Definir la condición lógica >>> Aplicar  
 
 Nota: Si se configuran los descuentos de línea a partir de parámetros , el propio sistema 
se encarga de comprobar que artículo cumple o no las condiciones. El resultado final es 
un descuento resultante de la suma de todos ellos. No se generan descuentos en cascada.   
  Nota: Es mucho más efectivo y práctico tener una sola tarifa y trabajar con políticas de 
descuentos que no a la inversa. El tener muchas tarifas puede hacer que sea inviable 
tenerlas actualizadas.

Alta e importación de clientes  
El cliente es la figura alrededor de la cual gira todo el proceso de ventas, pudiendo este 
darse de alta en la aplicación directamente o importarse masivamente a partir de los datos 
de los mismos en formato Excel a partir de una carga inicial.  
 
Para dar de alta un cliente,  
Módulo Ventas >>> Clientes >>> Pestaña Activos >>> Añadir Registro a la tabla >>> Editar 
y rellenar los campos necesarios >>> Insertar (F9)  
Para importar clientes masivamente,  
Módulo Ventas >>> Clientes >>> Pestaña Activos >>> Añadir Registro a la tabla >>> Limpiar 
Campos (Alt Sup) >>> Consultar (F7) >>> Importar >>> Aceptar >>> Abrir Fichero >>> 
Seleccionar el fichero de importación en formato Excel >>> Abrir >>> Importar  
Para obtener la plantilla Excel de importación de clientes,  
Módulo Ventas >>> Clientes >>> Pestaña Activos >>> Añadir Registro a la tabla >>> Limpiar 
Campos (Alt Sup) >>> Consultar (F7) >>> Importar >>> Aceptar >>> Plantilla >>> 
Guardar
