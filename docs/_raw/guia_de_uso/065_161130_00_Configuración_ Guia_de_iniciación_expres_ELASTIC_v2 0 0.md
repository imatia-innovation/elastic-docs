Guía rápida de iniciación  Configuración y parametrización  
Compras  
A continuación se enumeran los pasos a seguir para una correcta configuración y 
parametrización del sistema, en cuanto a la parte de compras se refiere. Aunque la parte 
de compras ha sido desarrollada simétrica a la de ventas, en realidad es un módulo mucha 
más sencillo en cuanto a cantidad de información. Por tanto este módulo para su puesta 
en marcha, necesita única y exclusivamente tener un maestro de proveedores.  
Alta o importación de proveedores  
El proveedor es la figura alrededor de la cual gira todo el proceso de compras, pudiendo 
este darse de alta en la aplicación directamente o importarse masivamente a partir de los 
datos de los mismos en formato Excel en una carga masiva inicial.  
 
Para dar de alta un proveedor,  
Módulo Compras >>> Proveedores >>> Pestaña Activos >>> Añadir Registro a la tabla >>> 
Editar y rellenar los campos necesarios >>> Insertar (F9)  
Para importar proveedores masivamente,  
Módulo Compras >>> Proveedores >>> Pestaña Activos >>> Añadir Registro a la tabla >>> 
Limpiar Campos (Alt Sup ) >>> Consultar (F7) >>> Importar >>> Aceptar >>> Abrir 
Fichero >>> Seleccionar el fichero de importación en formato Excel >>> Abrir >>> 
Importar  
Para obtener la plantilla Excel de importación de clientes,  
Módulo Compras >>> Proveedores >>> Pestaña Activos >>> Añadir Registro a la tabla >>> 
Limpiar Campos (Alt Sup) >>> Consultar (F7) >>> Importar >>> Aceptar >>> Plantilla 
>>> Guardar
