Módulo Finanzas >>> Informes  >>>  Cash flow  >>> Acciones >>> Configurar Cash Flow >>>  
Añadir registro >>> Seleccionar las subcuentas pertinentes >>> Insertar (F9)  
 
Repetir este último proceso tantas veces como cuentas se quieran tener en cuenta.  
 
Para configurar el cash flow,  
 
Módulo Finanzas >>> Informes  >>>  Cash flow  >>> Seleccionar el informe creado >>> 
Añadir registro >>> Añadir y configurar las líneas que componen el informe (tipo 
de línea, subcuentas, relación entre ellas, etc…) >>> Insertar (F9)  
 
Añadir tantos registros como líneas sean necesarias para configurar el informe Cash Flow.  
Si se desea recuperar la estructura del cash flow para el año siguiente, existe la opción 
de copiar cash flow.  
 
Análisis financiero  
 
A diferencia del informe Cash Flow, el análisis financiero permite crear un listado para 
análisis pero sin restringirlo a ningún tipo de cuenta. Esto permite a modo de ejemplo 
crear un informe para analizar el activo circulante si quisiésemos.  
 
Para crear el informe de análisis financiero , 
 
Módulo Finanzas >>> Informes >>> Informe financiero  >>> Acciones >>> Nuevo Informe  
>>>  Editar y rellenar los campos obligatorios >>>  Insertar (F9)  
 
Para configurar el cash flow,  
 
Módulo Finanzas >>> Informes  >>>  Informe financiero >>> Seleccionar el informe creado 
>>> Añadir registro >>> Añadir y configurar las líneas que componen el informe 
(tipo de línea, subcuentas, relación entre ellas, etc…) >>> Insertar (F9)  
 
Añadir tantos registros como líneas sean necesarias para configurar el informe financiero . 
Si se desea recuperar la estructura del informe financiero para el año siguiente, existe la 
opción de copiar cash flow.
