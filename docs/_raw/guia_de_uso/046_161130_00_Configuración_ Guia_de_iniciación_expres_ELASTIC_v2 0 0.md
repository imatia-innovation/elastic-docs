Configuración tipo de proveedor  
Al igual que en clientes, en proveedores se puede realizar el mismo tipo de configuración. 
A cada tipo de proveedor se le puede asociar una configuración, es decir, una serie de 
valores precargados (moneda, idioma, IVA,…) de modo que, cada vez que se cree el 
proveedor, se cargarán automáticamente dichos valores. Otra funcionalidad interesante 
es la de poder asignar a un tipo o grupo de proveedores una misma cuenta contable o grupo 
de subcuentas contables.  
Para configurar un tipo de proveedor, primero crear una configuración,  
 
Menú Aplicación >>> Configuración >>> Configuración de proveedores >>> Configuración 
>>> Insertar (F9) >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Una vez creada la configuración se crea el tipo de proveedor y se asocia la configuración 
tipo:
