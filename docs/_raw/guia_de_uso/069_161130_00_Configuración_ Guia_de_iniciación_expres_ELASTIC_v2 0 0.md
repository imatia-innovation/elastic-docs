Guía rápida de iniciación  Configuración y parametrización  
Alta de instalaciones productivas  
Una de las primeras labores reales del módulo de producción,  es definir las fábricas, líneas 
de producción, secciones y operaciones. Esto dará una estructura organizativa a la hora de 
crear las órdenes de producción.   
 
Para crear una fábrica,  
Módulo Producción >>> Instalaciones >>> Seleccionar Empresa en el árbol >>> Añadir 
Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
Para crear una línea de producción,  
Módulo Producción >>> Instalaciones >>> Seleccionar Fábrica en el árbol >>> Añadir 
Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
Para crear una sección,  
Módulo Producción >>> Instalaciones >>> Seleccionar Línea en el árbol >>> Añadir Registro 
a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
Para crear una operación,  
Módulo Producción >>> Instalaciones >>> Seleccionar Sección en el árbol >>> Pestaña 
Operaciones >>> Añadir Registro a la tabla >>> Editar y rellenar los campos 
necesarios >>> Insertar (F9)  
 Nota: Si se quiere saber el tiempo real imputado en las fabricaciones parciales a nivel 
máquina, hay que crear obligatoriamente una sección con una máquina, sino por el 
contrario se puede tener una sección con varias máquinas.  
 
VER VIDEO. Como crear instalaciones productivas.  
Alta de grupos de programación  
Para llevar a cabo las programaciones es necesario definir, al menos, un grupo de 
programación, en el que se relacionarán la fábrica, almacén y empresa que intervienen en 
la misma.
