Guía rápida de iniciación  Configuración y parametrización  
Finanzas  
A continuación se enumeran los pasos a seguir para una correcta configuración y 
parametrización del Módulo de finanzas.  
Alta cuentas bancarias  
A cada empresa dada de alta en el sistema, se les pueden agregar las cuentas bancarias 
necesarias con las que van a operar.  
Para añadir una cuenta bancaria a una empresa, proceder de la siguiente manera:  
 
Menú Finanzas >>> Auxiliares >>> Cuentas bancarias >>> Seleccionar Empresa en el árbol 
>>> Añadir registro a la tabla >>> Editar y rellenar los campos necesarios >>> 
Insertar (F9)  
 
También es posible añadir las cuentas bancarias desde el módulo Laboral:  
 
Módulo Laboral >>> Empresa y centros de trabajo >>> Seleccionar Empresa en el árbol >>> 
pestaña Cuentas bancarias >>> Añadir registro a la tabla >>> Editar, rellenar los 
campos necesarios >>> Insertar (F9)  
 
 Nota: Una vez dadas de alta las cuentas bancarias, estas deben tener subcuenta en el 
plan general contable. Se debe crear dicha subcuenta en la configuración del Tipo y 
Subtipo se le debe poner BCC a ambas para que el sistema interprete que son subcuentas 
vincul adas a cuentas bancarias. Desde las cuentas bancarias asociar ala subcuenta a cada 
cuenta según corresponda.  
 Nota: Para una mejor gestión es recomendable poner los 5 últimos dígitos de la cuenta 
bancaria  en la descripción de la subcuenta ejemplo. Ejem: 572.16 Banco Popular 
*****57243.  
 Nota: Se puede configurar una subcuenta de caja, para que actué como un banco y poder 
por tanto utilizarla en el flujo comercial si se van a realizar cobros al contado contra caja. 
Así el asiento realizado se asentará directamente en la cuenta caja. Para dar de alta una 
caja como entidad bancaria se puede seleccionar banco=0000, sucursal=0000 DC=0X y la 
cuenta puede ser del tipo 0000000001.
