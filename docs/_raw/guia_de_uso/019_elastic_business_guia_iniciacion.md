Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Módulo Ventas >>> Facturas >>> Pestaña No Contabilizadas >>> Doble clic sobre la 
factura deseada >>> Pestaña Líneas >>> Subpestaña Líneas >>> Botón Servicios de 
la tabla >>> Editar y rellenar los campos necesarios >>> Aceptar  
 
Nota: No es posible añadir directamente a la factura artículos que no estén marcados 
como de Servicios, ya que los artículos que interactúan con el almacén han de 
gestionarse por medio de albaranes.  
 
Para insertar albaranes en una factura,  
 
Módulo Ventas >>> Facturas >>> Pestaña No Contabilizadas >>> Doble clic sobre la 
factura deseada >>> Pestaña Líneas >>> Subpestaña Albaranes >>> Botón Añadir 
Albarán >>> Seleccionar el Albarán >>> Aceptar  
 
Para generar recibos a partir de una factura,  
 
Módulo Ventas >>> Facturas >>> Pestaña No Contabilizadas >>> Doble clic sobre la 
factura deseada >>> Pestaña Recibos >>> Botón Generar Recibos en la tabla  
 
Nota: El número de recibos generados y sus fechas de vencimiento, si bien son 
modificables, vendrán dados a priori por el Periodo de cobro  de la factura.  
 
Para generar apuntes , 
 
Módulo Ventas >>> Facturas >>> Pestaña No Contabilizadas >>> Doble clic sobre la 
factura deseada >>> Pestaña Apuntes  >>> Botón Generar apuntes  
Envíos   
El envío se crea con doble funcionalidad, la primera poder gestionar el envío real físico 
del día y la segunda, a través del cierre del envío, provocar la salida automática del 
contenido directamente del  almacén del contenido de ese envío.  
 
Para crear un nuevo envío,  
 
Módulo Ventas >>> Envíos >>> Pestaña Pendientes >>> Añadir registro a la tabla >>> 
Editar y rellenar los campos necesarios >>> Insertar (F9)
