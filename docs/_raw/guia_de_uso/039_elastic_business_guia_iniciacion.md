Subcuentas   
Una subcuenta es una partida dentro del Cuadro de Cuentas del Plan General Contable, 
que estará clasificada dentro de alguno de los apartados del mismo, a través de su 
codificación numérica.  
 
En este apartado es posible definir las subcuentas, su codificación, la cuenta a la que 
pertenecen, y otros datos que pueden ser interesantes como el porcentaje de I.V.A. que 
se le aplica o la cantidad presupuestada.  
 
Para consultar una subcuenta,  
 
Módulo Finanzas >>> Subcuentas >>>  Botón Mostrar Datos >>> Doble clic sobre la Cuenta  
 
Para crear una subcuenta,  
 
Módulo Finanzas >>> Subcuentas >>>  Botón Mostrar Datos >>> Añadir Registro a la tabla 
>>> Editar y rellenar los campos necesarios >>> Insertar (F9)  
Plan presupuestario   
El Plan Presupuestario es una previsión de gastos para un determinado espacio de 
tiempo. A través de este formulario puede comparar el gasto presupuestado por meses, y 
el porcentaje del mismo que es realmente realizado para cada subcuenta.  
 
Para consultar un Plan Presupuestario,  
 
Módulo Finanzas >>> Plan Presupuestario >>>  Botón Mostrar Datos
