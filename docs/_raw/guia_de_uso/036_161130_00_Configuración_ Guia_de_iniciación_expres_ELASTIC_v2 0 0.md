Guía rápida de iniciación  Configuración y parametrización  
Para añadir logo a la empresa:  
 
Menú Laboral  >>> Empresas y centros de trabajo >>> Seleccionar la empresa en el árbol 
>>> Botón Seleccionar Imagen >>> Seleccionar imagen >>> Pulsa Abrir.  
 
 Nota: Es importante tener en cuenta que no es posible borrar una empresa una vez ha 
sido creada.  
 Nota: Por defecto todos los clientes que se van creando se añaden automáticamente a la 
empresa creada por defecto. Si se quiere autorizar el uso de clientes ya creados a una 
empresa nueva, se deben asociar a la misma en la pestaña empresas y a posteriori crear 
la subcuenta contable a utilizar en el PGC de la nueva empresa.  
 Nota: Si se necesita, elastic® BUSINESS, permite crear divisiones comerciales dentro de 
la estructura de empresa. Esto permite tener logotipo y dirección personalizada.  
 
VER VIDEO. Crear o modificar una empresa. Crear divisiones  
Crear nuevos usuarios  y perfiles  
Para añadir un nuevo usuario a la aplicación se ha de seguir los siguientes pasos:  
 
Menú Administración >>> Usuarios >>> Botón Insertar (si previamente se ha consultado 
algún perfil, primero Botón Limpiar Campos. (Alt Supr)>>> Rellenar campos 
obligatorios: Usuario, Contraseña y Perfil. >>> Botón insertar.  
 
 Nota: Mientras no se creen otros perfiles a todos los usuarios se le deberá asignar el  
perfil Administrador.  
 Nota: No es posible, por integridad de datos, eliminar usuarios de la aplicación. Los 
administradores podrán bloquear o dar de baja dichos usuarios.  
 
VER VIDEO. Crear un nuevo usuario.  
 
Para crear un nuevo perfil, seguir los siguientes pasos:  
 
Menú Gestión de módulos >>> Perfiles >>> Botón Inserta >>> Rellenar campos obligatorios 
>>> Botón Insertar.  
 
 Nota: Los permisos de cliente y de servidor has de copiarlos tal cual están en el perfil 
Administrador.
