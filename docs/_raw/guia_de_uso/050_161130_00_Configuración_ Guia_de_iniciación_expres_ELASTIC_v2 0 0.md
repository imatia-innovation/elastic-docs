El plan presupuestario se crea automáticamente cuando se genera un P.G.C. y cualquier 
subcuenta añadida automáticamente se actualiza en el Plan presupuestario. Pro tanto la 
única funcionalidad disponible es la de dar saldos previsionales a cada una de las 
subcuentas mes a mes.  
Para configurar un plan presupuestario, proceder de la siguiente manera:  
 
Menú Finanzas >>> Plan presupuestario >>> Mostrar datos >>> Doble clic sobre al línea a 
editar >>> Pantalla subcuenta >>> Presupuestado >>> Editar mes a mes el saldo >>> 
Actualizar.  
 
 Nota: La modificación de los saldos se puede hacer accediendo directamente desde la 
subcuenta a través de la pestaña presupuestado.  
 Nota: Si la empresa ya tiene configurado un plan presupuestario desglosado mes a mes en 
un Excel, cabe la posibilidad de importarlo a través de Gestión de módulos >>> 
Importaciones /Exportaciones >>> EEcofinAsientos.

Dar de alta activos fijos  
Si la empresa lo desea, elastic® Business, permite llevar de manera automatizada la 
amortización de los activos de la empresa. Si los activos están dados de alta y 
perfectamente configurados (proveedor, factura asociada, subcuentas de dotación y 
amortizaci ón, periodos, etc…), se puede de una manera fácil e intuitiva generar todos los 
asientos de amortización. Se pueden pre generar de manera masiva todos los asientos de 
amortización de todos los activos configurados y amortizables.  
Si por el contrario la empresa decide llevar de manera manual a partir de una hoja de 
cálculo los valores de amortización y hacer un asiento manual, dicho módulo puede ser 
utilizado a modo de gestión o control de inventario de los activos.  
Para configurar un plan presupuestario, proceder de la siguiente manera:  
Menú Finanzas >>> Activos >>> Añadir registro >>> Configurar ficha de activo >>> Insertar 
(F9)
