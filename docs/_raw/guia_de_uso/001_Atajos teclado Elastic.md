## Texto extraído

 
Interno  ATAJOS DE TECLADO  EN ELASTIC  
1. ATAJOS DE TECLADO GENERALES  
- Esc: Cierra el formulario abierto  
- Ctrl + B : Bloquear  
- Ctrl + T : Minimizar  
- Ctrl + Alt  + T : Tareas en el servidor  
 
En los formularios en los que están los botones de “Aceptar” y “Cancelar”:  
 
- F3: Aceptar  
- F4: Cancelar  
 
2. ATAJOS DE TECLADO EN LOS DOCUMENTOS  
 
En todos los documentos de ventas  (presupuestos, pedidos, albaranes , facturas y 
recibos)  las siguientes teclas o combinaciones de teclas tienen el mismo 
comportamiento:  
 
- F5: Actualizar  
- F7: Consultar  
- F9: Insertar  
- F11: Actualizar  
- F12: Eliminar (esta acción sólo está permitida en los recibos)  
- Alt + -> : Navegar al registro siguiente  
- Alt + < - : Navegar al registro anterior  
- Alt + Supr  : Limpiar campos  
- Ctrl + P : Imprimir  
- Esc: Cerrar formulario
