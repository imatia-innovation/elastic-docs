Modelo 347  
 
El Modelo 347 permite generar un fichero electrónico para la importación en la oficina 
virtual de la agencia tributaria con la declaración de las operaciones realizadas con 
terceras personas, tanto clientes como proveedores, con las que hayamos superado a lo 
largo del año la cifra de 3000 euros.  
 
Para generar  el modelo 3 47, 
 
Módulo Finanzas >>> Informes  >>>  Modelo 3 47 >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Mostrar declarados  >>> Botón Generar informe  >>> Guardar el 
archivo en la ruta deseada >>> Aceptar  
 
Modelo 349  
 
El Modelo 349 permite generar un fichero electrónico para la importación en la oficina 
virtual de la agencia tributaria. Se trata de una declaración de la misma naturaleza que 
el modelo 347, es decir, de carácter informativo, si bien su periodicidad es trimestral y 
no es exclusiva de operaciones superiores a 3.000 euros.  
 
Para generar el modelo 349 , 
 
Módulo Finanzas >>> Informes  >>>  Modelo 349  >>>   Editar y rellenar los campos en la 
cabecera >>>  Botón Mostrar declarados >>> Botón Generar informe >>> Guardar el 
archivo en la ruta deseada >>> Aceptar  
 
Modelo 390  
 
La declaración modelo 390 es la declaración -resumen anual de todas las liquidaciones, 
bien trimestrales, bien mensuales, que se hayan presentado durante el ejercicio .
