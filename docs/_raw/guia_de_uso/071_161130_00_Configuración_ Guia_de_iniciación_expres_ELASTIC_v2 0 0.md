 Nota: Cuando se habla de todas las operaciones, se hace referencia a las de ese nivel. Si 
existen varios niveles de despiece de materiales y operaciones  en cada nivel se 
configuran los materiales y las operaciones de ese nivel.  
 Nota: En el despiece de materiales no solo se imputa la cantidad, sino según las 
necesidades se puede imputar el desperdicio que se genera, el tipo de consumo y el 
almacén y subalmacén de donde se debe realizar dicho consumo.  
 Nota: En el despiece de operaciones se debe imputar el tiempo de setup así como el 
tiempo unitario de fabricación. Se pude introducir la relación entre tiempo maquina 
y trabajador, así como si la operación se quiere que sea controlable y realice el 
consumo o el alta de producción.
