Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Para devolver recibos de la remesa de pago,  
 
Módulo Compras >>> Pagos >>>  Pestaña Enviadas >>> Doble clic sobre el Pago 
deseado>>> Pestaña Pendientes >>> Seleccionar Recibos >>> Botón Devolver 
Recibos en la tabla  
 
Para validar la remesa de pago,  
 
Módulo Compras >>> Pagos >>>  Pestaña Enviadas >>> Doble clic sobre el Pago 
deseado>>> Rellenar Fecha de Validación >>> Actualizar (F11)  
 
Para generar el cuaderno 34,  
 
Módulo Compras >>> Pagos >>> Doble clic sobre el Cobro deseado>>> Acciones  
 
Nota: A partir de los recibos devueltos se deben generar los nuevos recibos para enviar a 
cobro. Si se valida la remesa, el sistema detecta si existe algún recibo devuelto sin 
hijo y lo genera automáticamente.  
Gestión de apuntes (facturas, recibos y pagos)   
Mediante la gestión de apuntes es posible crear y borrar apuntes masivamente, pudiendo 
contabilizarlos o descontabilizarlos también de forma masiva.  
 
Para generar apuntes de facturas, recibos o remesas de pago,  
 
Módulo Compras >>> Gestión de Apuntes >>>  De Facturas, De recibos o De pagos >>> 
Pestaña No contabilizadas >>> Seleccionar Filas en la tabla que no tengan apuntes 
generados >>> Botón Crear  
 
Para borrar apuntes de facturas, recibos o remesas de pago,  
 
Módulo Compras >>> Gestión de Apuntes >>>  De Facturas, De recibos o De pagos >>> 
Pestaña No contabilizadas >>> Seleccionar Filas en la tabla con apuntes 
generados>>> Botón Borrar
