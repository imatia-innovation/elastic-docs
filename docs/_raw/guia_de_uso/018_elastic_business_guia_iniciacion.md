Módulo Ventas >>> Albarán >>> Pestaña No Expedidos >>> Doble clic sobre el albarán

Para expedir un albarán y que la mercancía se dé de baja automáticamente del almacén,  
 
Módulo Ventas >>> Albarán >>> Pestaña No Expedidos >>> Doble clic sobre el albarán 
deseado >>> Acciones >>> Expedir  
 
Para generar una factura a partir de un albarán,  
 
Módulo Ventas >>> Albarán >>> Pestaña No Facturados >>> Doble clic sobre el Albarán 
deseado >>> Acciones >>> Generar Factura  
 
Nota: Además de las funcionalidades enumeradas anteriormente es posible generar un 
albarán de abono y si el sistema detecta un albarán de abono dejará  devolver la 
mercancía al almacén si es necesario.  
Facturas   
En esta sección se exponen las funcionalidades básicas relacionadas con las facturas. En 
concreto se analizan las referentes a la creación de la cabecera de una factura, la 
asociación de albaranes a la misma y el registro de los recibos relacionados con el 
documento.  
 
Para crear una nueva factura bastará con insertar la cabecera de la misma,  
 
Módulo Ventas >>> Facturas >>> Pestaña No Contabilizadas >>> Añadir registro a la tabla 
>>> Editar y rellenar los campos necesarios >>> Insertar (F9)
