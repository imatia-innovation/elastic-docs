Revisión y configuración de tablas maestras  
Las tablas de datos maestros son un conjunto de tablas en las cuales se encuentran los 
datos de donde se alimentan los campos combo, así como determinados valores por defecto 
asociados a una lógica de ciertos procesos. Por tanto hay que tener especial cuid ado, pues 
determinadas modificaciones en estas tablas pueden acarrear funcionamientos indeseados 
en la aplicación.  
 
 Nota: La base de datos instalada ya dispone de datos precargados en las tablas maestras. 
Dichos datos son los valores más usuales utilizados por las empresas usuarias, aunque 
resulta aconsejable llevar a cabo una profunda revisión adaptándolas a los procesos rea les 
de la empresa.   
Existen dos pestañas de configuración para las tablas maestras.  
▪ Para acceder a las tablas maestras:  
Menú Aplicación >>> Configuración >>> Tablas maestras >>>Configuración >>> Seleccionar 
>>> Localizar tabla maestra, insertar o modificar valores >>> Aplicar.  
 
 Nota: Muchas de estas tablas maestras son accesibles desde otras partes de la aplicación 
(Hyperlinks, Formularios de configuración, etc.) para facilitar su configuración.  
 Nota: La tabla de configuración “GENERAL. Tablas auxiliares”,  contiene un listado con 
todas las tablas maestras.
