Guía rápida de iniciación  Configuración y parametrización  
Ventas  
A continuación se enumerarán los pasos a seguir para una configuración y parametrización 
del sistema, en cuanto a la parte de ventas se refiere. En realidad, menos el alta de 
clientes que es obligatoria, ya que si no se tiene un cliente o cliente potencial no se puede 
emitir presupuestos, etc…, el resto de funcionalidades son mejoras ergonómicas para el 
día a día. El sistema propone, pero el usuario siempre puede modificar y editar los datos. 
(Ejem: tengo una tarifa, el sistema propone precio de venta del a rtículo, pero obviando 
descuentos, el precio base se puede editar en el documento y queda asociado y guardado 
con el documento).  
Crear tarifas. Asignar PVP a los artículos  
El sistema permite crear múltiples tarifas y asociarlas a clientes según las necesidades. Se 
establecerá una por defecto y el resto son opcionales. Se puede tener una sola tarifa y 
jugar con política de descuento por clientes o grupos de clientes o incluso llegar a tener 
tarifas específicas por cliente o grupo de cliente. La recomendación es utilizar pocas 
tarifas y jugar con los descuentos asociados a clientes, ya que a posteriori resulta 
complicado y costoso mantener actualizadas las tarifas si hay muchas .  
 
Para crear una tarifa,  
 
Módulo Ventas >>> Tarifas >>> Insertar (F9)>>> Editar y rellenar los campos necesarios 
>>> Insertar (F9)  
 
Para añadir artículos a la tarifa,  
 
Módulo Ventas >>> Tarifas >>> Seleccionar Tarifa en el árbol >>> Pestaña Artículos >>> 
Añadir Registro a la tabla >>> Asociar artículos y precio base >>> Aceptar  
 
Para asignar los clientes que tendrá dicha tarifa,  
 
Módulo Ventas >>> Tarifas >>> Seleccionar Tarifa en el árbol >>> Pestaña Clientes >>> 
Añadir Registro a la tabla >>> Asociar Clientes >>> Aceptar
