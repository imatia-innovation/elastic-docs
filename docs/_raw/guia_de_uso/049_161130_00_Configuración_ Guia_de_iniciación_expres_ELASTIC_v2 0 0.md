Guía rápida de iniciación  Configuración y parametrización  
Previa de una configuración de los modelos de plantilla de asiento, a posteriori se  pueden 
recuperar e introducir los datos mediante un asistente. Se puede configurar desde las 
descripciones de las líneas que se van a introducir, hasta los importes result antes mediante 
formulas.  
Para configurar una plantilla, proceder de la siguiente manera:  
 
Menú Finanzas >>> Auxiliar >>> Plantillas de asientos >>> Añadir registro >>> Crear 
cabecera >>> Insertar (F9) >>> Configurar modelo.  
 
VER VIDEO. Como crear una plantilla de asiento y utilizarla.  
Crear modelos de apunte de gestión  
Los asientos que se generan desde la parte de gestión, se pueden hacer manualmente sobre 
la propia factura, mediante apuntes libre o bien, configurar un modelo de asiento y que 
sea la propia aplicación la que se encargue de generarlos siguiendo el modelo.  
Para configurar un modelo de apunte, proceder de la siguiente manera:  
 
Menú Finanzas >>> Auxiliar >>> configurar asiento contable >>> Insertar (F9) >>> 
Configurar el modelo de asiento >>> Insertar (F9)  
 
 Nota: Se pueden crear modelos de asientos para facturas de venta y compras, cobros y 
pagos de recibos independientes, cobros y pagos de recibos mediante remesas y pagarés.   
 Nota: El modelo de asiento está pensado para cubrir la generación de la mayoría de los 
asientos. Si existe una excepción, siempre resulta menos costoso generarlo a partir de un 
modelo muy similar y luego a partir del apunte libre editarlo.
