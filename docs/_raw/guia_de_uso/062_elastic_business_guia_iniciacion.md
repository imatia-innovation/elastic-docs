Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Todo informe de acción está asociado a una No Conformidad. Los informes de acción se 
pueden crear desde el formulario de Informes de acción ,  
Módulo Calidad  >>> Informes de acción  >>> Seleccionar el nodo del árbol  con en el tipo 
de No conformidad a crear  >>> Insertar (F9)  >>> Editar y rellenar los campos 
necesarios >>> Insertar (F9)  
 
También puede crearse un  informe de acción desde una No Conformidad,   
 
Módulo Calidad  >>> No conformidades  >>> Seleccionar la No conformidad deseada  >>> 
Pestaña Informes de acción asociados >>> Añadir registro a la tabla >>> Editar y 
rellenar los campos necesarios >>> Insertar (F9)  
Configuración registros de fabricación y ensayos   
La primera acción a llevar a cabo para configurar registros de fabricación y ensayos es 
crear los parámetros correspondientes,  
 
Módulo Calidad  >>> Configuración de registros de fabricación (o configuración de 
ensayos)  >>> Gestión de parámetros de registros de fabricación (o gestión de 
parámetros de ensayos)  >>> Añadir registro a la tabla >>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)  
 
Para llevar a cabo la configuración de los registros de fabricación y ensayos ,  
 
Módulo Calidad  >>> Configuración de registros de fabricación (o configuración de 
ensayos)  >>> Configuración de registros de fabricación (o configuración de 
parámetros de ensayos)  >>> Añadir registro a la tabla >>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)  
 
Nota: Una vez creados de los registros de fabricación y ensayos es posible incluir los 
parámetros definidos para completar la configuración .
