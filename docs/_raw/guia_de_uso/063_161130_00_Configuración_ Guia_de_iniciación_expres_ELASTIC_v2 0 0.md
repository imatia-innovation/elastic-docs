Alta de representantes  
Los representantes comerciales son las figuras sobre las que se aplicarán las comisiones 
definidas en el punto anterior.  
 
Para dar de alta un representante comercial,  
 
Módulo Ventas >>> Comerciales >>> Comerciales >>> Insertar (F9) >>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)  
 
Para asignar comisiones a un comercial,  
 
Módulo Ventas >>> Comerciales >>> Comerciales >>> Seleccionar Comercial en el árbol 
>>> Pestaña Comisiones >>> Añadir Registro a la tabla >>>Editar y rellenar los 
campos necesarios >>> Insertar (F9)
