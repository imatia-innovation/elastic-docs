Dar de alta conversión de unidades  
Los datos que se visualizan en esta entrada, corresponden con la tabla maestra 
Configuración conversión unidades, siendo esta entrada, una mejora a nivel ergonómico. 
En esta tabla se definen la conversión existe entre dos unidades previamente dadas de alta  
en la aplicación.  
La configuración y alta de conversiones implica la realización de los siguientes pasos:  
 
Menú Aplicación >>> Configuración >>> Conversión de unidades >>> Seleccionar unidad de 
origen y unidad de destino y dar valor al factor de conversión >>> Validar mediante 
tabulador.  
 
 Nota: Basta con definir la conversión en un sentido.  
Nota: Las unidades que se utilizan en los campos Unidad Origen y Destino, deben estar 
dadas de alta previamente en la tabla maestra “ALMACÉN. Unidades de medida generales.”  
 
VER VIDEO. Dar de alta unidades y conversión entre unidades.  
Configuración de monedas  
Esta entrada permite definir las diferentes monedas que se van a utilizar en la aplicación, 
cuál de ellas será la divisa que se utilice por defecto y el factor de conversión de las demás 
con respecto a esta.  
Para configurar las divisas se procede de la siguiente manera:  
 
Menú Aplicación >>> Configuración >>> Monedas >>> Dar de alta monedas, establecer pro 
defecto y poner la conversión >>> Validar mediante tabulador.
