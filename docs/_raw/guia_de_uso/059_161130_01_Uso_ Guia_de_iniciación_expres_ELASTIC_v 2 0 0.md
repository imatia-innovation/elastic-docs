Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
Trazabilidad  
A continuación se enumerarán de manera clara y concisa a modo de resumen, los pasos a 
seguir para el uso de cada una de las funciones de la aplicación. Si se quiere tener más 
conocimiento del uso de cada uno de los módulos o funcionalidades, ver con detalle cada 
uno de los manuales de módulo.  
Puntualizar que aquí se enumera la utilización de todas las funcionalidades disponibles 
en la aplicación que, no tiene por qué coincidir con la aplicación desplegada en el 
cliente.  
Navegador   
En el navegador es posible realizar una búsqueda por lotes,  
Módulo Trazabilidad  >>> Navegador  >>> Nodo Buscar en el árbol  >>> Limpiar campos 
(ALT Supr)  >>> Consultar (F7) >>> En la cabecera indicar los datos por los que se 
va a buscar el lote >>> Consultar (F7)  
Para obtener un listado de todos los lotes registrados,  
Módulo Trazabilidad  >>> Navegador  >>> Nodo Resumen completo en el árbol   
Buscador de documentos   
Para realizar  búsquedas a partir de algún dato que tengamos del lote ,  
Módulo Trazabilidad  >>> Buscador por documentos  >>> Indicar en la cabecera el número 
de documento en el campo correspondiente  >>> Consultar  (F7) 
Listado valoración de lotes   
Para obtener  un listado de lotes con costes ,  
Módulo Trazabilidad  >>> Listado de valoración de lotes  >>> Botón Consultar  
Configurador   
Para poder utilizar la trazabilidad esta ha de ser configurada previamente a su utilización 
y asignada a las familias.
