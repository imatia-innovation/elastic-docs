Alta de artículos  
Una vez creadas las familias, la generación de artículos se realiza de manera automática 
o bien se que crean manualmente, dependiendo de si se han configurado las familias por 
parámetros o no. Que se decida o no hacerlo por parámetros, no tiene ni porque s er una 
situación irreversible y o todos si o todos no. Según las necesidades de cada empresa se 
pueden configurar familias de una manera u otra.  
 
Para dar de alta los artículos de familias parametrizables se va a procede de la siguiente 
manera:  
 
Menú Almacén >>> Familias de artículos >>> Seleccionar Familia en el árbol >>> Pestaña 
Artículos >>> Añadir Registro a la tabla >>> Pantalla parámetros: seleccionar los 
parámetros que definirán la generación del artículo >>> Aceptar >>> Pantalla de 
artícul os, revisar campos y configurar lo que pueda faltar >>> Insertar (F9)  
 
Para dar de alta los artículos de familias no parametrizables se va a procede de la siguiente 
manera:  
 
Menú Almacén >>> Familias de artículos >>> Seleccionar Familia en el árbol >>> Pestaña 
Artículos >>> Añadir Registro a la tabla >>> Pantalla parámetros aceptar sin 
modificar nada >>> Pantalla de artículos, dar código y descripción al artículo >>> 
Insertar (F9)
