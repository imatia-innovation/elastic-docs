Guía rápida de iniciación  Configuración y parametrización  
Configuración y parametrización básica  
A continuación se enumeran los pasos a seguir para una configuración y parametrización 
básica del sistema. Puntualizar que no todos los pasos son necesarios ya que depende de 
los módulos contratados.  En esta parte se define a configuración de todas aquell as partes 
que son necesarias para poner en marcha el sistema. Obviamente  algunas de las 
configuraciones solo tienen sentido si se pone en marcha determinados módulos o 
funcionalidades.  
Empresa inicial   
Por defecto Elastic ya trae una empresa creada, denominada “EMPRESA” y un usuario con 
perfil administrador. “USUARIO” “ PERFIL”  
 
 Nota: Para que la aplicación funcione con los mínimos datos solo será necesario modificar 
los campos obligatorios (CIF/NIF, Nombre de empresa), marcar el check Por defecto, 
seleccionar una configuración de impresiones, añadir a la empresa una cuenta bancaria y 
personalizar su logo si se desea. Dicho logo o imagen es el que aparecerá en la cabecera 
de las impresiones estándar.  
 Nota: El resto de los datos solo son necesarios, si se va a utilizar el módulo de finanzas, 
ya que todos los datos para elaborar los informes obligatorios para presentar en Hacienda 
se recogen de estas pestañas.  
 
Para modificar los datos de la empresa creada por defecto proceder de la siguiente 
manera:  
 
Menú Laboral >>> Empresas y centros de trabajo >>> Seleccionar la empresa en el árbol 
>>> Modificar >>> Botón Actualizar.  
 
Para añadir una cuenta bancaria por defecto a la empresa:  
 
Menú Laboral >>> Empresas y centros de trabajo >>> Seleccionar la empresa en el árbol 
>>> Pestaña Cuentas bancarias >>> Botón Añadir registro >>> Añadir cuenta bancaría 
y marcarla como Por Defecto >>> Botón Insertar.
