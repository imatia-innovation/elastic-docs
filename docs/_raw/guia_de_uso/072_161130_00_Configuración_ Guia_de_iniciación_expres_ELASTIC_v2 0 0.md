Guía rápida de iniciación  Configuración y parametrización  
Calidad  
En el módulo de calidad, la configuración o parametrización para su puesta en marcha 
afecta básicamente a la parte de calidad de control. La creación de parámetros de 
seguimiento, la creación de modelos de registros par a el seguimiento de las fabricaciones 
así como la creación de modelos de ensayos de calidad , forman parte del paquete inicial 
configurable para la puesta en marcha del mismo.  
Una vez configurados y generados los modelos se debe definir donde se quieren aplicar.   
Alta de parámetros y configuraciones de registros de fabricación  
Para llevar a cabo los registros de fabricación la primera tarea será definir los parámetros 
o variables que aparecerán en los informes de dichos registros  
 
Dar de alta parámetros,  
Módulo Calidad >>> Configuración de registros de fabricación >>> Gestión de parámetros 
de registro de fabricación >>> Añadir Registro a la tabla >>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)  
Para crear una configuración de registros de fabricación,  
Módulo Calidad >>> Configuración de registros de fabricación >>> Configuraciones de 
registro de fabricación >>> Añadir Registro a la tabla >>> Editar y rellenar los 
campos necesarios >>> Insertar (F9)  
Para asignar los parámetros anteriormente creados a una configuración de registros de 
fabricación,  
Módulo Calidad >>> Configuración de registros de fabricación >>> Configuraciones de 
registro de fabricación >>> Doble clic sobre un Tipo de Configuración >>> Añadir 
Registro a la tabla >>> Editar y rellenar los campos necesarios >>> Insertar (F9)
