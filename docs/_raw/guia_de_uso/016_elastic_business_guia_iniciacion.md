Guía rápida de iniciación  Como utilizar elastic® BUSINESS  
 
Módulo Ventas >>> Presupuestos >>> Pestaña Abiertos >>> Doble clic sobre el 
presupuesto deseado >>> Acciones >>> Nueva versión  
 
Para generar un pedido a partir de un presupuesto,  
 
Módulo Ventas >>> Presupuestos >>> Pestaña Abiertos >>> Doble clic sobre el 
presupuesto deseado >>> Acciones >>> Generar Pedido  
 
Nota: Las funcionalidades permitidas desde el presupuesto son, crear una nueva versión, 
clonar el presupuesto y generar pedido.  
Pedido   
Siguiendo la coherencia de diseño en los documentos del flujo de ventas, la ventana del 
pedido posee dos secciones perfectamente diferenciadas, en la parte superior la 
cabecera y en la parte inferior un conjunto de siete pestañas donde se muestran los 
datos e  información referentes al pedido.  
 
Para crear un nuevo pedido bastará con insertar la cabecera del mismo,  
 
Módulo Ventas >>> Pedidos >>> Pestaña No Expedidos >>> Añadir registro a la tabla >>> 
Editar y rellenar los campos necesarios >>> Insertar (F9)  
 
Para insertar líneas con artículos en el pedido (los artículos han de estar previamente 
insertados en la aplicación),  
 
Módulo Ventas >>> Pedidos >>> Pestaña No Expedidos >>> Doble clic sobre el pedido 
deseado >>> Pestaña Líneas >>> Subpestaña Líneas >>> Botón Artículo de la tabla 
>>> Editar y rellenar los campos necesarios >>> Aceptar  
 
Para generar un albarán a partir de un pedido,  
 
Módulo Ventas >>> Pedidos >>> Pestaña No Expedidos >>> Doble clic sobre el pedido 
deseado >>> Acciones >>> Generar Albarán  
 
Nota: Las funcionalidades permitidas desde el pedido son, descompletar, generar albarán 
directamente e incluso factura todo junto o clonar el pedido.
