Etiqueta QR duradera  
En la generación de las etiquetas de producto en los pedidos de compras se 
generará a mayores una nueva etiqueta para artículos trazables 
visualizando el logo,  el número de lote y un código QR con información del 
producto.  Este código QR contendrá una dirección URL donde consultar 
información del producto.  
 
 
                                     
Etiqueta QR duradera  
 
No necesita meter información de las etiquetas para esta impresión se 
imprimirá una etiqueta por la línea  de pedido.  El texto que se muestra en la 
parte inferior no es un número de lote, ya que en el pedido de compras 
todavía no existirán lotes. Lo que se va a mostrar será el valor con el que se 
van a generar a posteriori los números de lote.  
 
Estas etiquetas también será posible imprimirlas desde dentro del pedido de 
compras en la pestaña de líneas.
