Etiqueta de compra  desde pedido  
 
Este número de lote vendrá predefinido  por Número de pedido + Código del 
artículo .  
Las etiquetas de productos  también se pueden generar desde el Almacén . 
Para ello se ira a Almacén >> Procesos >> Etiquetas que es donde se 
generarán las etiquetas cuando no haya pedidos de compra . Las etiquetas 
de productos generadas manualmente  desde Elastic o la PDA  (sin relación 
con pedidos de compras  o albarán de compras ), para artículos trazables 
incluirán a mayores el número del lote. Para la generación de estas 
etiquetas será necesario seleccionar el lote además del artículo.
