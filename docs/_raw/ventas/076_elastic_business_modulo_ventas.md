Manual de Usuario Módulo de Ventas  
   
 
 
elastic® B USINESS   Pág. 76 de 84 
 
 Dirección  
Campos de Dirección, País, Provincia, Localidad y C.P.  
La selección de país filtra provincias y localidades.  
Estos datos sirven para generar los asientos contables con la cuenta fiscal correcta.  
 
Banco  
Cuenta bancaria: desplegable con las cuentas habilitadas para la empresa.  
Entidad, Oficina, DC y Cuenta: se rellenan al elegir el IBAN o manualmente si es uno nuevo.  
IBAN / SWIFT -BIC: imprescindibles para transferencias internacionales.  
Bloqueo de edición tras la primera contabilización.  
 
Otros datos  
Gastos: importe de comisiones, timbres u otros costes asociados.  
Se pueden especificar como porcentaje o cantidad fija.  
Validación para evitar que los gastos superen un porcentaje configurable del importe principal.  
 
Observaciones  
Campo multilineal libre para apuntes internos, histórico de cambios o instrucciones al departamento de 
contabilidad.  
 
 
En la parte inferior del formulario hay cuatro pestañas que amplían la funcionalidad:  
Básico  
Vista principal con todos los campos descritos anteriormente.  
Recibos  
Listado de recibos electrónicos o físicos generados a partir del pagaré.  
Botones para crear, importar o exportar recibos en formatos SEPA o local.  
Apuntes  
Muestra el asiento contable vinculado: débitos y créditos automáticos según la configuración de 
contabilidad.  
Permite previsualizar antes de contabilizar y corregir errores de cuadratura.  
Ficheros  
Área de arrastrar y soltar para adjuntar PDFs, imágenes o documentos escaneados.  
Cada fichero queda asociado al registro y se indexa para búsquedas posteriores.
