 Facturación impresa  Establece si las facturas deben imprimirse y entregarse 
físicamente al cliente o si se manejarán por otros 
medios.  
Ignorar calcular portes  Si está marcado, el sistema omitirá el cálculo 
automático de los portes (gastos de envío) para este 
cliente.  
Agrupación 
facturación  Permite consolidar varios albaranes en una sola factura 
según criterios definidos (fecha, tipo de pedido, etc.).  
Facturación por email  Habilita el envío automático de facturas a la dirección 
de correo electrónico del cliente, promoviendo la 
facturación electrónica.  
Albarán no facturable  Indica que los albaranes generados para este cliente 
no deben ser facturados. Puede usarse para entregas 
sin coste o muestras.

cliente . La moneda nos vendrá cubierta por defecto en euros.
