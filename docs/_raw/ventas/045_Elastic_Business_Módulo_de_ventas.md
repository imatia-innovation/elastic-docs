•Artículos: Permite seleccionar los artículos deseados siempre y cuando estén dados de alta 
en el sistema. Para facilitar el uso, se permite añadir artículos a la Cesta de artículos, mediante 
el botón Añadir a cesta.  
•Configurador: Permite la creación o selección de artículos paramétricos en el sistema. Si a 
la hora de completar los parámetros de un artículo, este ya está creado, el sistema ya lo 
añadirá al documento, de no ser así, preguntará si se desea crear.  
•Agrupaciones: Las agrupaciones están formadas por artículos físicos existentes agrupados 
en un artículo ficticio, son el equivalente a los Kits.  
•Histórico de precios: Permite consultar el histórico de precios.  
•Actualizar costes: Permite actualizar los costes de los artículos en función de propiedad 
configurada.  
 
 
Al hacer doble click en una línea del pedido, se abrirá una ventana con información relativa 
al artículo de la línea.  
En el detalle ampliado se permite configurar una comisión manual, así como especificar 
diferentes datos de entrega si así se desea.  
 
 
Observaciones: Observaciones del detalle.  
Observaciones internas: Observaciones del detalle para uso interno.  
 
 
En esta pestaña se permite añadir si de desea comerciales adicionales. Al añadirse estos se 
precargar, si está configurada, su comisión en función del detalle de la línea. De igual manera 
se permite añadir una comisión manual marcando el check de “Manual”  
 
 
En esta pestaña se permite editar el despiece de un artículo si este lo tiene configurado, o 
añadir uno manualmente para este pedido.  
Para ello primero se debe activar el check de “Despiece variable”, este check habilita la 
inserción y modificación del despiece del artículo.
