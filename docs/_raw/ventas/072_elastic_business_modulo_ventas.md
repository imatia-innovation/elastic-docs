 Apuntes : se generan los apuntes de un recibo según la configuración. Según se van poniendo como 
pagados o no pagados, se van generando apuntes.  
Ficheros : se asocian documentos digitalizados, capturados o bien desde un origen a destino, o 
arrastrados a la pestaña y adjuntados directamente.  Se puede escanear directamente un documento y 
adjuntarlo directamente a la pestaña.  
SII: aparecen los datos de envío del cliente  
 
Hay dos formas de crear recibos en la aplicación:  
• Desde las facturas de forma manual ( Ventas  >> Facturas >> Pestaña recibos >> Generar 
recibo)  
• Automáticamente cuando se generan los apuntes. ( Ventas  >> Gestión de cobros  >> Recibos >> 
Pestaña apuntes)  
  
 
Los anticipos se usan para gestionar aportaciones monetarias para un proveedor antes de haber hecho 
una compra o adelantar una transferencia bancaria sin que se haya emitido una factura.  
Los anticipos se muestran agrupados por estados:  
• Pendientes: se muestran los anticipos pendientes de ejecutarse para un proveedor.  
• Validados: se muestran los anticipos que ya han sido aplicados a un proveedor.  
• Eliminados: se muestran todos aquellos recibos de anticipo que han sido eliminados.  
Desde el formulario de búsqueda, una vez localizado el anticipo, se accede a él mediante doble clic 
sobre el detalle. El formulario posee dos secciones perfectamente diferenciadas  
En la parte superior se encuentra la cabecera del anticipo.  
En la parte inferior se sitúa un conjunto de dos pestañas, donde se muestran los datos e información 
referentes al anticipo.  
 
En la cabecera se encuentran los datos principales del anticipo. Los datos obligatorios son el nombre 
del proveedor, el importe, la moneda, la conversión y la fecha de creación.  
 
Recibos : aquí se muestran los recibos generados de un anticipo.  
Fichero : se pueden asociar documentos digitalizados, capturados o bien desde un origen a destino, o 
arrastrados a la pestaña y adjuntados directamente. Se puede escanear directamente un documento y 
adjuntarlo directamente a la pestaña  
Crear un anticipo  
Para crear un anticipo. Se deben insertar todos los datos obligatorios de proveedor, moneda, importe y 
conversión.
