En este apartado se incluyen respuestas a las preguntas más habituales que pueden 
surgir tras la implantación del sistema VERI*FACTU.  
 
Si se necesita modificar un campo que no está regulado por el Reglamento de 
Obligaciones de Facturación (ROF), como una dirección o un texto de observaciones, 
puede editarse directamente en la factura. Sin embargo, cuando la modificación afecta 
a informaci
 ón patrimonial o fiscal (importes, tipos de IVA, razón social, bases imponibles), 
es obligatorio generar una factura rectificativa.  
Con carácter general, una factura emitida no puede modificarse. Para corregirla debe 
crearse una nueva factura rectificativa. Existen dos tipos:  
• 
Factura rectificativa por sustitución: anula por completo la factura original y la 
sustituye por una factura nueva con los datos corregidos.  
• 
Factura rectificativa por diferencias: ajusta únicamente el importe o concepto 
afectado, sin anular la factura original.  
Una factura rectificativa puede crearse dando de alta una nueva factura y seleccionando 
el tipo correspondiente: tipo de factura, tipo de rectificativa, factura rectificada, etc.  
Para realizar un abono, desde el albarán puede generarse un albarán de abono mediante 
la acción de 
 Generar albarán de abono
 . Este proceso crea un albarán negativo para la 
devolución de mercancía, que posteriormente se podrá facturar generando una factura 
rectificativa por diferencias.
