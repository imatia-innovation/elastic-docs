A partir de ahora la AEAT validará los NIF de los clientes. Para ello se incorpora un sistema 
de comunicación entre Elastic y la AEAT que permite realizar esta validación de forma 
automática.  
Antes de mostrar la nueva funcionalidad, se incluyen algunas recomendaciones para 
evitar errores al introducir un NIF:  
• 
Juego de caracteres recomendado: 0123456789ABCDEFEGHJKLMNPQRSTUVXYZ. 
No se recomienda usar letras minúsculas.  
• 
Espacios en blanco: si se utilizan, debe ser un único espacio y nunca más de uno.  
Caracteres especiales permitidos: guion medio "
 -
", guion bajo "_", barra inclinada 
"/", punto "."  
• 
Si la identificación de la factura incluye una serie, se aconseja que la serie 
aparezca primero, seguida del número de factura y separada por un espacio.  
• 
El número de factura no debe comenzar con espacios en blanco; el texto debe 
ir alineado a la izquierda.  
Al crear un cliente es necesario indicar de forma exacta el tipo de identificación fiscal 
que se usará para él.
