Ilustración 33 –Recibos de ventas. Básico.  
El comportamiento del sistema varía según el estado del recibo:  
• 
Si el recibo no ha sido cobrado, basta con pulsar el botón Eliminar. El recibo 
quedará marcado como eliminado.  
• 
Si el recibo ya ha sido cobrado, el sistema mostrará un mensaje de error al intentar 
eliminarlo y no permitirá marcarlo como eliminado. Para anularlo, debe utilizarse 
la opción Anular cobro. Esta acción marcará el recibo como eliminado y generará 
un asient
 o contable de signo contrario que compensa el asiento del cobro 
original.
