Manual de Usuario Módulo de Ventas  
   
 
 
elastic® B USINESS   Pág. 36 de 84 
 
 Cuando pulsemos el icono, se nos desplegará una ventana donde tendremos que seleccionar una familia 
(si queremos usar la configuración previa que tiene cada una. Esto se explicará en el módulo almacén) 
o añadir valores para el artículo.  
 
 
**Nota:  lo más conveniente para crear un artículo es usar los parámetros que tienen configurados las 
familias.  
Tras crear el artículo nos mostrará una ventana donde podemos añadir tres campos fundamentales:  
- Código externo.  
- Descripción externa  
- Precio unitario  
 
 
Para finalizar se tiene que pulsar OBLIGATORIAMENTE  la cruz verde para añadirlo.  
 
**Nota:  si solamente se conoce el comienzo del código del artículo, se puede escribir acompañado de 
un “*”, de esta manera el sistema abrirá una ventana para la selección de los artículos que comiencen 
con esos primeros dígitos indicados.
