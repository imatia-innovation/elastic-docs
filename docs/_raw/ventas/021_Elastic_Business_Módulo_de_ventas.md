Rec. Equiv  Recargo de equivalencia configurado por defecto

Tipo de venta  Ventas  que realiza el cliente . Este campo se arrastrará 
a facturas y albaranes por defecto.  
De baja  Habrá que completar el campo de fecha para darlo 
de baja.  
Evaluable  Entrará en el grupo de clientes  sujetos a evaluación.  
En cuarentena  Habrá que completar el campo de fecha para que 
este entre en cuarentena.  
Criterio de caja  La liquidación del IVA se hace solo cuando el cliente  
cobra.  
Agrupar facturación  Se agrupan los albaranes del cliente  al hacer una 
facturación múltiple . 
Cliente  de consigna  Cuando se compra su mercancía entra en consigna.  
Albarán no facturable  No se facturan los albaranes.  
 
Nº Copias original : Sirve para indicar el número de facturas que se imprimirá con el texto definido en el 
campo de “Texto copias original”.  
Texto copias original : Texto que se mostrará en las facturas impresas por primera vez.  
Texto duplicado : Texto que se mostrará en las facturas impresas después de las originales.  
Los campos de Bloqueado  y De baja  se cubren con una fecha. Una vez cubierta el cliente pasa al estado 
de dicho campo.  
Ocasional:  Marca a este cliente como no habitual. Se utiliza para ventas puntuales o esporádicas, y 
normalmente no requiere seguimiento comercial frecuente ni condiciones de crédito permanentes.  
Interno:  Identifica al cliente como interno a la empresa (por ejemplo, sucursales, empleados u 
operaciones internas). Las ventas asociadas a este cliente no se consideran como ventas comerciales 
externas y pueden tener un tratamiento contable especial.  
 Campo  Descripción  FACTURACIÓN  Cta. banc. en recibo  Indica si debe aparecer la cuenta bancaria del cliente 
en el recibo de cobro. Útil para facilitar el pago 
mediante transferencia o domiciliación.  
No imprimir albarán  Si se activa, los albaranes generados para este cliente 
no se imprimirán automáticamente, reduciendo el uso 
de papel en operaciones digitales.  
Frecuencia de 
facturación  Define cada cuánto tiempo se generarán las facturas 
para este cliente (ej. semanal, mensual, trimestral).
