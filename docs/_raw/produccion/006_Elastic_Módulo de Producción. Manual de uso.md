Pág. 6/35 www.imatia.com   
El apartado de grupos de operaciones sirve para la combinación de varias operaciones en una misma. 
Para ello habrá que ir a Producción >> Grupo de operaciones . 
 
Lo primero que se debe hacer es añadir un código y una descripción para la operación que vamos a 
crear. Tras especificar estos y clicar en el símbolo de añadir se podrán incluir las operaciones que 
deseemos combinar en el siguiente menú.  
 
 
Por último, deberemos especificar qué acciones queremos que se realicen con cada una de las 
operaciones mediante un check. Estos checks son:  
- Consumo:  esta operación consume materiales  
- Alta producción:  esta operación dará de alta el articulo final (solo puede estar marcado en una 
columna)  
- No generar orden:  no genera operaciones
