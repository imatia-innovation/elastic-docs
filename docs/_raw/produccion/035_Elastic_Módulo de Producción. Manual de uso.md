Pág. 35/35 www.imatia.com   
Este listado se utiliza para consultar todos los  costes  desglosados y al detalle de todas las  órdenes  de 
fabricación del sistema. Permite comparar el grado de cumplimiento a nivel costes, enfrentando los 
costes reales desglosados frente a los costes teóricos  desglosados .  Para acceder , Listados >> 
Listados de programación >> Costes por fabricaciones.   
Para que se muestre la información se debe pulsar la lupa de la esquina superior derecha.  
 
 
Para hallar el coste real y coste teórico, se requiere el siguiente cálculo:  
- Coste teórico  = Coste teórico materia prima + Coste teórico empleado + Coste teórico maquina 
+ Coste teórico fijo operaciones  + Otros costes teóricos  
Coste teórico  = 17.414€ + 0€ + 0€ + 17,000€ + 0€ = 34.414€  
 
- Coste real  = Coste real materia prima + Coste real empleado + Coste real maquina + Coste real 
fijo operaciones + Otros costes reales  
Coste real = 17.414€ + 0€ + 0€ + 24,120€ + 0€ = 41.534€  
 
 
Este listado se utiliza para consultar todo  lo relacionado con el seguimiento de ordenes de fabricación 
del sistema. Permite conocer  tanto los tiempos de fabricación de cada una de las programaciones,  
como  las cantidades fabrica das, las que están pendientes, las rechazadas y las defectuosas . También 
permite conocer al detalle , donde se está haciendo dicha programación  (Fábrica, línea, sección…) . Para 
acceder , Listados >> Listados de programación >> Control de fichajes .  
Para que se muestre la información se debe pulsar la lupa de la esquina superior derecha.
