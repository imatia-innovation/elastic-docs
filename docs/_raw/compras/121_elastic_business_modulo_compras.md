Aquí mostraremos un ejemplo de cómo  se reparte el importe de gasto tanto fij o, variable  y mixto  según 
las unidades  de las líneas mencionadas anteriormente.  
 
Para repartir est as unidades  tendremos que tener en cuenta lo siguiente:  
- Cantidad  (A): 100 
- Cantidad  (B): 50 
- Gasto fijo: 100€  
 
Seguiremos una serie de pasos para llegar al importe:  
1) Ponderaremos que peso tiene cada artículo  en la Base imponible  
Porcentaje (A): Cantidad  (A) / Cantidad  total = 100/150  = 66.67%   
Porcentaje (B): Cantidad  (B) / Cantidad total = 50/150  = 33.33 %  
 
2) Multiplicaremos el Gasto fijo por los porcentajes  
Importe (A): Gasto fijo * Porcentaje (A) = 100€ * 66.67 % = 66.67 € 
Importe (B): Gasto fijo * Porcentaje (B) = 100€ * 33.33 % = 33.33 €
