Este caso es una mezcla de los dos anteriores y para repartir el importe y el porcentaje tendremos que 
tener en cuenta  lo siguiente:  
- Base imponible (A) 8.397€  
- Base imponible (B): 3.216€  
- Base imponible total (A+B): 11.613€ (8.397€ + 3.216€)  
- Gasto fijo: 100€  
- Gasto variable: 10%  
 
1) Saber cómo se reparte el  Gasto fijo . (explicado en el punto 2.1.1)  
Importe (A): Gasto fijo * Porcentaje (A) = 100€ * 72 ,31% = 72,31€ 
Importe (B): Gasto fijo * Porcentaje (B) = 100€ * 27 ,69% = 27,69€ 
 
2) Saber cómo se reparte el Gasto variable . (explicado en el punto 2.1 .2) 
Importe (A): Base imponible (A) * Gasto variable (%) = 8 ,397€ * 10% = 839,70€  
Importe (B): Base imponible (B) * Gasto variable (%) = 3 ,216€ * 10% = 321,60€ 
 
3) Sumar Gasto fijo más el Gasto Variable.  
Importe total (A): Reparto gasto fijo (A) + Reparto gasto variable (A)= 72,31€ + 839,70€ = 912,01€ 
Importe total (B): Reparto gasto fijo (A) + Reparto gasto variable (A)= 27,69€ + 321,60€= 349,29 €
