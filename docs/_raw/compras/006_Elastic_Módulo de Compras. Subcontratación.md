Compras >> Subcontratación  
 
A la hora de seleccionar la línea y darle a “Generar pedidos”, el sistema preguntará si se quiere hacer el 
pedido de ventas de consigna.  
Este pedido de venta sirve para generar un albarán de venta, que se utiliza para la gestión de salida de la 
mercancía al proveedor.  
El sistema creará los siguientes documentos:  
• Pedido de compra a proveedor.  
• Pedido de venta a cliente (mismo que el proveedor)  
• Albarán de venta a cliente (mismo que el proveedor) expedido automáticamente.  
El movimiento del artículo que se envía al proveedor se gestiona como un traspaso a un almacén de 
consigna previamente configurado.  
El pedido de compras se generará con una línea , esta hará referencia al artículo servicio asociado al 
proceso de subcontratación.  
En la descripción aparecerá concatenado tanto el artículo servicio como el artículo a recibir.
