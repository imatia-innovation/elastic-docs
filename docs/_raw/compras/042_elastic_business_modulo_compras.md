Existen diferente forma de añadir una línea, aunque al final se consigue el mismo resultado. En este caso 
vamos a diferenciar varias situaciones:  
1. Podemos crear líneas sin necesidad de enlazarlo con artículos. Funcionaría como si fuera un 
campo de texto para realizar anotaciones.  
 
2. Insertar artículos a través de su código, es decir, escribir en la columna código el código del 
artículo y nos autocompletará toda la información.  
 
3. Introducir un artículo mediante el icono “Artículos”. Al pulsar el icono nos aparece un desplegable 
con tres subpestañas:  
 
a. Artículos proveedor : los cuales hacen referencia a los artículos que tiene relacionado el 
proveedor en su ficha.  
b. Todos los artículos : muestra todos los artículos creados.  
c. Cesta de artículos : muestra artículos añadidos.  
En estas subpestañas solo tiene que cubrirse la cantidad de artículo y el precio si se necesita.  
 
 
 
Para añadir un nuevo artículo que no existe en el almacén, tendremos que pulsar el icono de Configurar. 
Este botón sirve permite la creación o selección de artículos paramétricos en el sistema. Si a la hora de 
completar los parámetros de un artículo, este ya está creado, el sistema ya lo añadirá al documento, de 
no ser así, preguntará si se desea crear.  
Cuando pulsemos el icono, se nos desplegará una ventana donde tendremos que seleccionar una familia 
(si queremos usar la configuración previa que tiene cada una. Esto se explicará en el módulo almacén) 
o añadir valores para el artículo.
