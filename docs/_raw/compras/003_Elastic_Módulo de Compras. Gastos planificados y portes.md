Aquí mostraremos un ejemplo de c ómo se reparte el importe de gasto tanto fijo , variable  y mixto  según 
el importe de las  líneas mencionadas anteriormente.  
 
Para repartir este importe tendremos que tener en cuenta lo siguiente:  
- Base imponible  (A) 8.397€  
- Base imponible (B): 3.216€  
- Base imponible total  (A+B) : 11.613€ (8.397€ + 3.216€)  
- Gasto fijo : 100€  
 
Seguiremos una serie de pasos para llegar al importe:  
1) Ponderaremos que peso tiene cada articulo en la Base imponible  
Porcentaje (A): Base imponible (A) / Base imponible total = 8.397€/11.613€ =  72.3 1%  
Porcentaje (B): Base imponible (B) / Base imponible total = 3.216€/11.613€ = 27.69%  
 
2) Multiplicaremos el  Gasto fijo por los porcentajes  
Importe (A): Gasto fijo  * Porcentaje (A) = 100€ * 72.31% = 72.31€  
Importe (B): Gasto fijo * Porcentaje (B) = 100€ * 27.69% = 27.6 9€

- Base imponible (A) 8.397€  
- Base imponible (B): 3.216€  
- Gasto variable : 10%
