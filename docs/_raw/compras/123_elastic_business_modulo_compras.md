Pág. 7/15 www.imatia.com   
 
Este caso es una mezcla de los dos anteriores y para repartir el importe y el porcentaje tendremos que 
tener en cuenta lo siguiente:  
- Cantidad (A): 100  
- Cantidad (B): 50  
- Base imponible (A) 8.397€  
- Base imponible (B): 3.216€  
- Base imponible total (A+B): 11.613€ (8.397€ + 3.216€)  
- Gasto fijo: 100€  
- Gasto variable: 10%  
 
1) Saber cómo se reparte el Gasto fijo. (explicado en el punto 2. 2.1) 
Importe (A): Gasto fijo * Porcentaje (A) = 100€ * 66.67% = 66 ,67€ 
Importe (B): Gasto fijo * Porcentaje (B) = 100€ * 33.33% = 33 ,33€ 
 
2) Saber cómo se reparte el Gasto variable . (explicado en el punto 2. 2.2) 
Importe (A): Importe ponderado (A) * Gasto variable (%) = 7 ,742€ * 10% = 774 ,20€ 
Importe (B): Importe ponderado (B) * Gasto variable (%) = 3 ,871€ * 10% = 387 ,10€ 
 
3) Sumar Gasto fijo más el Gasto Variable.  
Importe total (A): Reparto gasto fijo (A) + Reparto gasto variable (A)= 66,67€ + 774,20€ = 840,87€  
Importe total (B): Reparto gasto fijo (A) + Reparto gasto variable (A)= 33,33€ + 387,10€ = 420,43€
