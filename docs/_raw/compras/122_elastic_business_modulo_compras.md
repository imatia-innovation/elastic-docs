Pág. 6/15 www.imatia.com   
 
 
Para repartir este porcentaje  tendremos que tener en cuenta lo siguiente:  
- Cantidad (A): 100  
- Cantidad (B): 50  
- Base imponible (A) 8.397€  
- Base imponible (B): 3.216€  
- Base imponible total (A+B): 11.613€ (8.397€ + 3.216€)  
- Gasto variable: 10%  
 
Seguiremos una serie de pasos para llegar al importe:  
1) Ponderaremos que peso tiene cada artículo en la Base imponible  
Porcentaje (A): Cantidad (A) / Cantidad total = 100/150 = 66.67%  
Porcentaje (B): Cantidad (B) / Cantidad total = 50/150 = 33.33%  
 
2) Multiplicaremos la Base imponible total por los porcentajes  
Importe  ponderado  (A): Base imponible total * Porcentaje (A) = 11.613€ * 66.67% = 7.742 € 
Importe  ponderado  (B): Base imponible total * Porcentaje (B) = 11.613€ * 33.33% = 3.871 € 
 
3) Multiplicamos el importe ponderado por porcentaje del Gasto variable  
Importe (A): Importe ponderado (A) * Gasto variable (%) = 7.742€  * 10% = 774.20€  
Importe (B): Importe ponderado (B) * Gasto variable (%) = 3.871€  * 10% = 387.10€
