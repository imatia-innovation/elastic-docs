En el caso de que una línea de artículo no vaya a ser recibido tanto total como parcialmente, 
para que no esté permanentemente el pedido en la pestaña de  Pendiente,  existe la opción de 
marcar como completa esa línea. Con esta acción se consigue que el sistema interprete que no 
van a servir las líneas marcadas a pesar de que quede cantidad pendiente de recibir.  
En el caso de que el usuario se equivoque y marque líneas no deseadas como completas, 
existe la acción de descompletar para revertir el problema. Esta acción se usa si todo el 
pedido figura como recibido, si no se podría hacer manualmente sobre las mismas.   
Si se selecciona la acción "Descompletar", el sistema muestra una ventana emergente con 
todas las líneas que figuran en estado de completas para proceder a su desmarcado. En ese 
momento el pedido es devuelto a la pestaña de  Pendientes  para continuar con la expedición de 
la parte descompletada.  
 
 
Cuando hemos finalizado el pedido, podremos generar el albarán, la cual nos mostrará una ventana 
emergente donde podremos poner la referencia del albarán del proveedor.  Al final del proceso, el sistema 
informará del nº de albarán generado y dará la posibilidad de ir al formulario a verlo.
