En este apartado podemos poner una fecha de inicio y una final para que durante ese plazo no se pague 
al proveedor. Hay un check donde podemos marcar que se repita anualmente  
 
 
 
En este apartado podemos podremos poner hasta que riesgo nos acepta el proveedor. En la aplicación 
saltará un aviso si nos pasamos de este. Tendremos que clicar en la cruz verde y nos mostrará una 
ventana donde aparecen los campos que tendremos que cubrir,  obligatorios son el código y el límite.  
El límite es el importe hasta lo que nos cubre el proveedor (vendrá dado por el código) y el código es con 
quien gestiona el riesgo el proveedor, como por ejemplo CESCE. Para crear el código del riesgo 
tendremos que ir a Aplicación >> Configuración >> Tabl as maestras.  
 
 
 
Esta pestaña vendrá completada por defecto ya que coge la empresa donde se haya creado el proveedor. 
Si hay multiempresa podrán añadirse las que se necesiten y relacionarlos mediante códigos
