En esta ventana se va a detallar el funcionamiento de la subcontratación en Elastic, así como su 
configuración y preparación de datos para su carga. Este apartado tiene relación con diferentes módulos 
de Elastic, así que nos iremos desplazando entre ellos y podremos encontrar más información en sus 
respectivos manuales.  
 
 
La subcontratación en Elastic se define como una operación más en el proceso de fabricación de un 
artículo.  
Esta se definió pensando en la utilización de referencias distintas para los artículos implicados en este 
proceso de subcontratación. Es decir, se envía a un proveedor la referencia A, se realiza el proceso 
pertinente a la subcontratación, y vuelve al sist ema la referencia B.  
Al entender esta en el sistema como una operación más, lo primero que se debe hacer es definir las 
secciones y operaciones como de subcontratación.  
Para ello se debe acceder a Producción >> Instalaciones >> Fabricas >> Líneas >> Secciones.  
A continuación, se explican los diferentes checks y campos a cubrir.  
• Sección externa : check para indicar que es una sección externa, este check se trasladará 
automáticamente a las operaciones creadas aquí.  
• Proveedor : se indica si la sección pertenece a un proveedor específico. Esta información se 
trasladará automáticamente a las operaciones creadas aquí.  
• Familia de servicio/artículo de servicio : se especifica un artículo servicio para los trabajos de 
subcontratación en esta sección. Esta información se trasladará automáticamente a las 
operaciones creadas aquí. El artículo servicio se puede asociar directamente a nivel de operación 
e incluso a ni vel de despiece de artículo.
