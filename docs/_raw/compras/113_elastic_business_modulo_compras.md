En este apartado vamos a ver cómo es posible crear una valoración para los proveedores en forma de 
nota numérica y en que nos podemos basar. En primer lugar, s e configura n previamente con los 
parámetros necesarios a tener en cuenta en dicha evaluación  y luego pasaremos a evaluarlos.  
 
En esta parte de la aplicación se configuran todos los parámetros que se deben tener en cuenta a la hora 
de poner una nota a un proveedor.  Para llegar aquí nos iremos a Compras >> Evaluación de proveedores 
>> Configuración.   
La pantalla está dividida en las siguient es pestañas:  
• Fórmulas:  se crean y se muestran todas las fórmulas creadas para la evaluación de 
proveedores.  
• Procesos:  se crean y consultan todos los procesos necesarios para la aplicación de las fórmulas.  
 
 
Para que funcionen las evaluaciones a proveedores, se deben crear primero los procesos.  
Una vez en la pantalla de inserción  podemos ver que hay dos subpestañas (consulta y puntuaciones)  se 
debe añadir un código , una descripción del proceso  y una consulta SQL para que tengamos un proceso .
