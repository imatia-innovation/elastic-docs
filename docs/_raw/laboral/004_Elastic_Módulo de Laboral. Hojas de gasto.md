Básico – Remesa de gastos  
 
El cuerpo está formado por:  
• Básico  
Aquí se selecciona el banco deseado  donde se cargará la remesa.  
• Hojas de gasto  
Aquí se añaden las hojas de gasto que queremos incluir en la remesa.  Para ello se tiene que pulsar el 
icono que está del recuadro rojo.  
 
Hojas de gastos – Remesa de gastos  
 
• Apuntes  
Una vez se cubra la fecha de envío al banco  se podrá cubrir la fecha de pago . Se crea el apunte 
contable una vez esta última esté cubierta .
