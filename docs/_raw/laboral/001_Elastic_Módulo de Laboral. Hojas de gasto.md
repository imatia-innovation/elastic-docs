Pág. 1/5 www.imatia.com   
En este documento vamos a detallar como  crear  Hoja s de gasto s. Basándonos en la s configuraciones  
actuales de  las hojas de gasto , realizaremos una explicación de cómo  será el  proceso para llevar a cabo 
la creación  de una y todas las configuraciones relacionadas.  
 
Para comenzar,  se han  configurado  dos nuevos tipos de asientos contables que se pueden ver en 
Aplicación >> Configuración >> Configuración de asientos contables.   
• LAB. Hojas de gastos  
• LAB. Remesas hojas de gastos.  
 
Se creará una hoja de gasto y se irá explicando cada uno de sus apartados. La hoja de gasto se encuentra 
en Laboral >> Hojas de gastos.   
La cabecera se compone de:  
• Empleados : Muestra un desplegable con los empleados.  
• Forma de pago : Campo informativo de la hoja de gasto , este se arrastra a la columna de Forma 
de pago al insertar gastos.  
• Concepto : Descripción  de la hoja de gasto  
El cuerpo tiene 3 pestañas:  
• Gastos : Aquí se introducen todas las líneas de la hoja de gasto . 
o Banco del empleado : En el caso particular  de BMC no aplica.   
o Banco empresa : En este campo de cubrirá la tarjeta VISA del empleado  cuando la forma 
de Pago sea VISA.  Las subcuentas contables de las VISA deben estar configuradas con 
el tipo CBG.  
 
Columnas:  
 
o F. gasto : Fecha con la que se quiere registrar el gasto.  
o Desc. Gasto : Este campo se muestra en la impresión de la hoja  y describe brevemente 
el motivo de la línea de gasto.  
o Cantidad : Se introduce como multiplicador del precio . Se creó esta posibilidad para los 
precios que se introducen en los tipos de categoría. En este ejemplo se puede ver que 
hay un 2 en las comidas por el n úmero de menús  o 100 por los kilómetros con el coche.  
o Cuenta  gasto : Campo que se cubre por defecto una vez  se introduce la categoría.  
o Tarjeta : Campo no obligatorio donde se pondrá la tarjeta con la que se pagó.  Una vez 
que el campo de Cuenta bancaria se añade la tarjeta , no es necesario cubrir este campo.  
o Categoría : Se muestra un desplegable con las categorías que se hayan creado con 
anterioridad en las tablas maestras.  
o Precio : Precio unitario  definido en la categoría.  
o Importe : Cantidad x Precio.
