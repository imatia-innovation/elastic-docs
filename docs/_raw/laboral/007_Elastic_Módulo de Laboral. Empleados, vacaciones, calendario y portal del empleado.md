En Elastic se da la posibilidad de consultar varios listados relativos a la jornada laboral, vacaciones, etc:  
• Vacaciones/incidencias : Este listado se utiliza para consultar el número de días de vacaciones 
totales, asignados, pendientes y asignados sin disfrutar que tiene un empleado. También 
muestra los días de incidencias que pueda tener.  
• Tabla de vacaciones/incidencias : Este listado se utiliza para consultar las vacaciones e 
incidencias que tienen los empleados en un periodo de tiempo determinado , pero en formato 
tabla . Es obligatorio poner un rango de fechas para el que se quiere consultar.   
• Incidencias laborales . En este listado se pueden validar las vacaciones.  
• Situación empleados : Este listado muestra datos relativos a la antigüedad del empleado, tipo de 
contrato , etc.  
• Formación complementaria : Este listado muestra datos relativos a la formación del empleado.  
• Horas por empleado : Este listado se utiliza para consultar las horas teóricas y las horas 
registradas por empleado, así como los días de vacaciones, días laborables, etc.  
• Registro de jornada por empleado : Este listado se utiliza para comparar el tiempo total frente al 
tiempo teórico por empleado, así como, las horas al día frente al tiempo total.  
• Control de jornada anual : Este listado se utiliza para comprar el tiempo total frente al teórico,  
pero a nivel anual.
