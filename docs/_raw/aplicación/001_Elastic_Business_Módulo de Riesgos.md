En el presente documento se va a detallar el funcionamiento del módulo de riesgos de Elastic Business.  
 
Para comenzar a utilizar la funcionalidad del módulo de riesgos de Elastic Business, es necesario 
definir una fórmula para el cálculo de este riesgo . 
Para ello, se debe acceder mediante la siguiente ruta : Aplicación >> Configuración >> Módulo Riesgos.  
Una vez dentro se pueden definir diferentes tipos de riesgo:  
• Ventas: riesgo genérico para clientes.  
• Compras: riesgo genérico para proveedor es. 
• Grupo de clientes: riesgos específicos por grupos de clientes.  
Una vez se seleccione el tipo de riesgo que se quiere crear, se debe pulsar la cruz verde ubicada en la 
parte  superior.  Una vez pulsada, se activarán los campos y tablas inferiores.  
A continuación,  se explica el proceso de creación del riesgo.
