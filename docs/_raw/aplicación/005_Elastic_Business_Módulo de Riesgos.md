## Texto extraído

 
 
 
 
 
 
 
 
 
Pág. 5/7 www.imatia.com  Nota : A través de  propiedades, se puede bloquear tanto el pedido como el cliente si el importe de este 
supera  el riesgo configurado. Estas propiedades deben ser configuradas  por administradores de Elastic 
Business.  
Se mostrará el siguiente mensaje  cuando se supere el umbral del riesgo.  
 
Tanto en el cliente como en el pedido  se cubrirán sus correspondientes fechas de bloqueo.  
 
 
La configuración es similar  a la de clientes. Para asociar el riesgo a los grupos de clientes se debe 
acceder a la siguiente ruta: Ventas >> Clientes >> Grupos >> Riesgo.  
 
 
 
Para acceder  al riesgo de proveedores  se debe seguir la siguiente ruta:  Compras >> Proveedores >> 
Administración >> Política de pago >> Riesgo.  
Para el caso de los proveedores no se dispone de un desglose de riesgo, sino que simplemente se indica 
el riesgo que concede el proveedor.
